# 鹈鹕渡 · The Pelican Crossing

一只白鹈鹕骑着复古邮政自行车，沿着黄昏的海堤公路跨海而行。会飞的鸟，选择骑车——这就是全部叙事。

## 怎么看

- 直接用 Chrome **双击打开 `pelican/index.html`**（`file://` 即可运行，不需要起服务）。首次加载 Three.js 需要联网访问一次 jsDelivr CDN。
- 开场是一段一镜到底的推近镜头；之后鼠标**拖拽旋转、滚轮缩放**，数字键 `1–6` 或直接调 `window.__bench.setView(id)` 切换六个机位。
- 点击车铃（或按 `B`）会响铃；按 `M` 静音。音频全部由 WebAudio 当场合成，无外部文件。

## 结构成立（底线自查）

- **脚踩踏板**：两条腿用两骨 IK 每帧解算，脚踝位置直接取自曲柄旋转后的踏板世界坐标，脚蹼搭在踏板上随曲柄转动。
- **翅膀搭车把**：折叠翼沿背线覆羽，腕部伸出小臂落在把套上，能看到腕关节。
- **自行车能骑**：完整车架（上管/下管/立管/前叉/后叉）、辐条交叉编法的轮组、齿环+蜘蛛臂牙盘、链条绕飞轮运行、脚踏曲柄、前后挡泥板、货架+邮包铺盖、前篮+鱼、车灯、车铃——机械关系按真实自行车布置。

## 场景里有什么

落日海面波光（顶点着色波浪+高光）、海堤公路与标线、会闪灯的灯塔和小岛、浮标、盘旋的海鸥、远处一只飞过的鹈鹕剪影（题眼）、尘埃光点随"骑行"向后流动、车篮里的鱼、车后架上的邮件铺盖。Bloom + 暗角 + 胶片颗粒做后期氛围。

## 契约接口

```js
window.__bench.views          // ['side','front','three_quarter','top','closeup_head','closeup_legs']
window.__bench.setView(id)    // 平滑过渡 ~0.9s
window.__bench.listParts()    // 124 个命名部件（id/name/parent 树）
window.__scene / window.__renderer / window.__camera
```

## 值得多看两眼的地方

1. **`closeup_head`**：眼睛、粉色眼圈、细长喙挂着喉囊、围脖围巾、背后海面波光——最像"肖像"的一张。
2. **`closeup_legs`**：牙盘齿、链节、蜘蛛臂、橙脚蹼踩在踏板上——机械成立的证据。
3. **`side` / `three_quarter`**：落日逆光剪影 + 长影 + 车灯，整组海报感最强。

## 实现说明

单文件 `pelican/index.html`（约 65KB），Three.js 0.160.1 经 importmap 从 jsDelivr 加载，其余全部程序化生成：几何由 LatheGeometry/TubeGeometry/自定义 BufferGeometry 拼装，纹理用 Canvas 现画（路面、波光、柳条、信封），无任何外部图片/模型/音频/字体。

## 自检

用 Playwright（file:// 真浏览器）逐项点过：六个机位全部可切且画面互异，拖拽/滚轮生效，`listParts()` 返回 124 项，控制台无错误。自检脚本与截图在 `_dev/`（不属于交付物）。
