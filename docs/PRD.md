# Bench Workbench v2 · 产品需求与工程拆分

## 1. 第一性原理：为什么做这个项目

一个新模型发布后，要回答的问题只有两个：

1. **对我（评测者）**：它在我真正关心的编码任务上到底行不行？——要用最少的操作把 8 道题跑完、评完。
2. **对访客（读榜的人）**：这个结论可信吗？——要能看到排名、差异，以及评分规则本身。

因此工作台的全部价值 = **把「选题 → 下发 → 交付 → 预览 → 评分 → 出榜」这条链上每一步的摩擦降到最低**，并把**方法论**作为可公开阅读的文档。任何不服务于这条链的东西（在面板里驱动 Agent 做题、复杂的任务队列页）都降级或去掉。

人工做一次评测的最短路径（设计目标）：

| 步骤 | 旧版 | 新版 |
|---|---|---|
| 登记模型 | 填表：供应商、名称、harness… | 只输入 `GPT-6.1-Sol`，供应商、目录、图标自动 |
| 取提示词 | 新建运行弹窗 → 复制 | 题目页顶部 Tab 选题 → 「复制提示词」一键（自动建工作目录、开始计时、可选打开 harness） |
| 知道模型做完没 | 手动点“结束”并粘贴最后回复 | 工作台轮询工作目录：交付文件按清单逐项点亮；模型写出 `FINAL_MESSAGE.md` 即自动结束计时 |
| 看效果 | 进预览舞台手动开 | 运行卡片「预览」→ 全屏舞台 + 右侧浮动评分面板 |
| 评分 | 去“评审”页 | 预览同屏打分（键盘 0–3、J/K 切项）；Agent 项复制「AI 评审提示词」交给评分 Agent |
| 看结果 | 排行页 | 排行勾选即对比；任何图表一键导出 PNG/SVG；一键打包全部图表 |

## 2. 信息架构（左侧导航）

```
评测                      执行                      结果                      文档
├ 总览  /                 └ 运行  /runs             ├ 排行榜  /board          └ 方法论  /docs/<节>
├ 模型  /models             （进行中/待评/已完成）   ├ 对比    /compare
└ 题目  /tasks/<Txx>                                 └ 导出    /exports
底栏：设置 /settings · GitHub · 下载源码 · 主题 · 连接状态
```

- 预览舞台不再是一级导航，而是运行的一种「模式」（`/stage`，从运行、文件、URL 进入），全屏。
- 后台任务（评分、导出）变成顶栏右侧的任务托盘（Popover），不占导航。
- 系统设置（harness、TTS、存储文件、依赖、CLI 接入）合并进「设置」。
- 方法论文档独立路由，访客无需理解工作台操作即可阅读：概览、设计原则、雷达维度、题目×维度、题目关系、评分体系、运行协议、导出表格、评分工具。

## 3. 功能需求

### 3.1 模型
- **R-M1** 新增模型只需名称；按名称规则推断供应商（`gpt/o\d/codex→OpenAI`、`claude→Anthropic`、`gemini/gemma→Google`、`deepseek→DeepSeek`、`qwen/qwq→Alibaba`、`glm/chatglm→Zhipu`、`kimi/moonshot→Moonshot`、`grok→xAI`、`doubao/seed→ByteDance`、`minimax/abab→MiniMax`、`mimo→Xiaomi`、`hunyuan→Tencent`、`ernie→Baidu`、`step→StepFun`、`mistral/codestral→Mistral`、`llama→Meta`…），可改。
- **R-M2** 保存即创建 `model/<供应商>/<模型>/`（供应商目录不存在则创建）。
- **R-M3** 头像使用真实品牌图标（lobe-icons，MIT），打包在本地（离线可用），按供应商/系列匹配；无匹配时用首字母玻璃徽章。
- **R-M4** 根据供应商推荐默认 harness（从本机已检测到的软件中选择），可改；模型档案保存 harness。
- **R-M5** 模型详情：维度雷达、逐题得分、运行列表、单模型报告生成。

### 3.2 题目
- **R-T1** 顶部 Tab（T01–T08，含 T03 A/C 变体）横向并列，选中即显示该题；URL 深链 `/tasks/T05`。
- **R-T2** 主操作「复制提示词」：提示词 = **统一运行约定头** + prompt.md 原文（已处理 A/C 段、T06 分隔线、TTS 占位符）。约定头包含：题号、工作目录绝对路径、交付文件夹名、必须存在的文件清单、`FINAL_MESSAGE.md` 要求、时间上限、禁止事项。
- **R-T3** 「为谁复制」模型选择器（记住当前测评模型）。复制时若该模型该题没有未开始的工作目录则自动新建 `rN/`（复制预置素材）并记录开始时间。
- **R-T4** 「复制并打开 harness」：复制后启动模型绑定的 harness（桌面应用 exe / 命令行在工作目录打开终端）。默认关闭，需在设置中启用。
- **R-T5** 题目详情：背景信息卡、交付清单、门槛、检查项（按维度/层级/方式筛选、搜索）、0–3 锚点、注入缺陷表（T08）、提示词原文。

### 3.3 运行
- **R-R1** 运行看板：进行中 / 已交付待评 / 已评分，卡片显示模型头像、题号、计时、交付清单进度。
- **R-R2** 交付检测：服务端每 3 秒扫描未完成运行的工作目录，比对交付清单；`FINAL_MESSAGE.md` 出现即自动写入最后回复并结束计时（以文件时间为准）。变化通过 SSE 推送并提示。
- **R-R3** 一键「登记并自动评分」（bench-grader init-run + grade）。
- **R-R4** 「预览」：打开舞台（HTML / 视频 / 开发服务器），同屏浮动评分面板：该运行的人工项，键盘 0/1/2/3 打分、J/K 切换、N 写备注，可选盲评。
- **R-R5** 「AI 评审提示词」：复制给评分 Agent（如 DeepSeek Harness）的提示词，指明 skills 路径（`.agents/skills/…`，备用绝对路径）、run_id、`wb pending/score` 用法与证据要求。
- **R-R6** 运行详情：计时、用量、最后回复、提示词留档、文件浏览、得分明细、门槛。

### 3.4 结果
- **R-B1** 排行榜：名次（含并列）、质量分与 95% CI、9 维热力、达标率、期望成本/用时；多选即对比。
- **R-B2** 对比：雷达叠加、逐题分组柱、维度差值表、效率散点；可从排行勾选或 URL 进入。
- **R-B3** 所有图表支持导出 PNG（2×）/ SVG / 复制到剪贴板。
- **R-B4** 导出中心：一键打包全部图表（ZIP）、bench-grader 全量导出（CSV/MD/XLSX/PNG/HTML）、存储文件导入导出、单模型报告批量生成。

### 3.5 文档 / 开源
- **R-D1** 方法论文档路由，原生组件重构（不嵌 iframe），含图表：维度权重雷达、题目×维度热力矩阵、题目关系图、检查项分层/方式分布。
- **R-D2** 底栏 GitHub 图标链接仓库；「下载源码」由服务端打包 `git archive` ZIP（排除 hidden）。

### 3.6 Skills 与 CLI
- **R-S1** `skills/` 为源，服务启动时镜像到 `.agents/skills/`（Agent 软件约定目录），并在 AI 评审提示词里给出两个路径。
- **R-S2** CLI 新增：`wb prompt <题号> --for <供应商/模型>`（带约定头）、`wb ai-prompt <run_id|ref>`、`wb detect`、`wb harness list|open`。修复带空格的参数值（`--k=v` 与引号）。

### 3.7 非功能
- **N1** 视觉：iOS Liquid Glass——多层半透明材质（backdrop blur + saturate + 亮度）、边缘高光（内描边渐变）、镜面反光层、柔和投影、连续圆角、胶囊分段控件；动效 180–320ms 弹簧曲线；尊重 `prefers-reduced-motion` 与 `prefers-reduced-transparency`。**禁止实心蓝色按钮**：主按钮为高亮玻璃（白/墨色填充 + 高光），强调色仅用于状态与焦点。
- **N2** 统一组件：Button、IconButton、Select（自绘下拉，键盘可用）、Menu、Popover、Tooltip、Tabs、Segmented、Dialog、Sheet、Toast、Table、Avatar、Badge、Kbd、Empty、Chart 容器。**不使用原生 select/datalist**。
- **N3** 无障碍：可见焦点环、键盘可达、aria 角色、对比度 ≥ 4.5（玻璃上的文字加 vibrancy 底）。
- **N4** 安全：只监听 127.0.0.1；拒绝非本机 Host（防 DNS 重绑定）与跨源；写操作需 token；harness 启动只允许已登记的可执行文件。
- **N5** 可移植：`data/bench-store.json` 仍是唯一持久化文件。
