# CASA GRIGLIA — 逼真的建筑（实时渲染）

**交付物**：`photoreal-building/index.html`，单文件，Chrome 直接双击打开即可（也用 `file://` 与本地 http 两种方式实测通过）。Three.js r160 从 jsDelivr 固定版本加载，带 unpkg / skypack 双回退；除这一个库之外，场景中没有任何外部资源——所有贴图都是运行时画进 `<canvas>` 的，所有几何都是代码拼的，天空是手写着色器。

## 建了什么

一栋九层的清水混凝土网格楼，落在城市转角地块上：

- **外骨架**：4.8m 柱距的清水混凝土柱 + 1.1m 高通长板模横梁，玻璃退后 0.55m 形成深凹网格，阴影是真实投影不是画的。梁面是程序绘制的板模混凝土（木纹板条、对拉螺栓孔、滴水锈痕、接缝）；柱子有专门的竖向板模贴图和气孔。
- **幕墙**：低铁玻璃带逐格明度/冷暖/粗糙度差异（"quilted"反射是真实玻璃的标志），1.2m 铝竖梃，~30% 的格子挂了半拉的百叶，少数房间是黑的。
- **室内**：每层有楼地面、内柱、双核心筒、成排办公桌和显示器剪影，以及带灯槽的吊顶——白天只亮少数几格，**黄昏整栋楼亮起来**。
- **大堂**：两层通高，再退 1.7m 形成柱廊，内有木饰面背景墙、前台、吊灯槽、蚀刻铜牌 "CASA GRIGLIA"（canvas 字体，系统字体）。
- **屋面**：女儿墙、碎石基层、金属板机房、露台栏杆、两台屋面机组、天线和红色障碍灯（黄昏亮）。
- **场地**：石材铺地广场（1.45m 分缝）、镜面水景（顶点波纹 + 环境反射）、行道树（树干 + 交叉叶片卡，叶影是真实 alpha 投影）、长椅、车挡、花池、两条带标线/斑马线/缘石的街道、两辆停放的车、五根带挑臂的街灯。
- **背景**：三圈共 15 栋配楼，白天是沉静的暗窗立面，黄昏各自按随机密度亮起暖窗。

## 渲染手段

- ACES 色调映射 + sRGB 输出，4096 PCFSoft 阴影。
- 自定义天空穹顶着色器：三段大气渐变 + 太阳盘/前向散射光晕 + fbm 卷云与低积云（缓慢漂移），黄昏自动变成橙紫渐变。
- 天空着色器同时喂给 PMREM 环境捕获（白天/黄昏两版），玻璃、水面、车漆的反射全部来自它，所以黄昏时反射是暖的。
- 水面是低粗糙度 + envMap + 顶点正弦涟漪。
- 转场用墙钟时间驱动（1.5s cubic ease），任何帧率下都按时到位；`dusk` 视角同时插值太阳位置/颜色、半球光、雾色、天空 uniforms、环境贴图、所有自发光强度和曝光。
- 后期氛围走两个 DOM 覆盖层：径向暗角 + 90ms 轮换的程序化胶片颗粒（弱、overlay 混合）。

## 交互与接口

- 拖拽环绕 / 滚轮缩放 / 右键平移，自写控制器带阻尼；右下角有五个视角按钮。
- `window.__bench = { views, setView, listParts }`（`listParts` 返回 16 个注册部件树节点），`window.__scene` / `__renderer` / `__camera` 均挂出。
- `setView` 后 1.5s 内画面稳定；控制台无错误（仅 PMREM 读回时有一条 WebGL 驱动级性能警告，非脚本问题）。

## 自检

`_dev/shoot.mjs`（Playwright）对五个视角逐一截图并收集控制台输出，`_dev/shot_*.png` 是实拍结果。经多轮迭代修掉了：无头低帧率下转场不达标（改为墙钟）、背景楼群吞掉相机、东路贴图方向错误导致的横向色带、广场过曝、白天背景楼黄窗过跳等。

## 没做完 / 可以更好的地方

- 玻璃是透明+反射近似，没上 transmission 折射（成本和收益不划算）；
- 配楼只是带窗贴的盒子，近看会露馅；
- 没有行人、没有车流动；场景是"静物建筑摄影"的路子——为了摄影感我刻意把一切弄得很安静。

**我最想让你看的**：`detail` 视角的板模梁/螺栓孔/内透，和 `dusk` 视角整栋楼亮起来、背景城市星星点点的那个瞬间。
