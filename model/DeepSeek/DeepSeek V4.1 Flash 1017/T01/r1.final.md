## 建模与物理实现思路（≤200 字）

统一米制世界坐标与单一状态机同时驱动两模式：物理采用 120 Hz 定步长积分，后轮按 ω = v / R 累加保证无打滑，曲柄按 ω_曲柄 = ω_后轮 × 16/44 保证齿比；踏板只平移、始终水平；腿为两段 IK（股骨 200 mm + 胫跗骨 420 mm），踝下接短跗跖骨与全蹼足并锁定踏板中心。2.5D 用分层内联 SVG + 视差滚动 + 逐部件 JS 变换；3D 用 Three.js 程序化几何与 Canvas 程序纹理、PMREM 环境反射、2048² 软阴影；共享状态使切换不重播。

## 实现要点

- **2.5D（SVG）**：海岸黄昏分层场景（天空/云/海/岸/公路/前景五层视差滚动）；车架、双轮、牙盘、飞轮、曲柄、双踏板、双腿、躯干、双翼、尾羽、S 形颈、头、钩喙、摆动喉囊、全蹼足均为独立 SVG 元素，由 JS 逐帧驱动，不是静态图。
- **3D（Three.js）**：程序化自行车与褐鹈鹕（球体/圆柱/管/挤出几何 + Canvas 程序贴图 + PMREM 环境反射）；暖色主光 castShadow + 2048² PCFSoft 阴影，地面与公路接收阴影；自写鼠标/触控轨道旋转与缩放，道具随里程循环滚动。
- **模式切换**：420 ms 交叉淡化，两种模式共享同一状态机，骑行相位与速度完全延续（过渡期间双模式同时渲染，不重播）。
- **物理与骨骼**：定步长积分可在掉帧时按墙钟追帧；踏板相对地面倾角恒为 0；脚-踏板距离 ≤ 3e-16 m，髋-鞍座恒为 0.02828 m；速度为 0 时车轮、曲柄、踏板、腿部与次级动画全部静止。
- **生物准确性**：页面标注 *Pelecanus occidentalis*（褐鹈鹕）；灰褐羽、乳白头颈、淡黄眼、深灰面颊、长喙钩尖、可见且摆动的喉囊、全蹼四趾、短粗腿且“反折关节”为踝关节、S 形颈、覆羽/次级飞羽/初级飞羽多层、翅膀扶把与平衡；成年鹈鹕基本不发声已在说明面板注明为艺术化处理。
- **音效**：Web Audio 实时合成——链条/飞轮咔哒频率随踏频、胎噪与风噪音量/滤波随速度、偶发低沉短鸣；首次交互后才创建 AudioContext，并提供静音开关。
- **界面与性能**：FPS 角标、模式切换、0–8 m/s 速度滑块、音效开关、物种与参数说明面板（含齿数、轮径、轴距、传动比等常量）、响应式无变形；`window.__bench` 全部接口与 `window.__scene` / `window.__renderer` 均已实现。
