# AETHER-9 · 重型可复用运载火箭 — 交互式官网

交付物：`aether9-site/` 静态站点，全部视觉资产由代码当场生成（几何、贴图、
光照、字体效果、粒子、音效合成），**零外部图片/模型/音频/字体文件**，
运行时**零网络请求**（Three.js r160 已本地 vendor 化在 `vendor/three/`）。

## 运行

```bash
cd aether9-site
python -m http.server 8080        # 或任何静态服务器
# 打开 http://localhost:8080/index.html
```

入口即 `aether9-site/index.html`，无需构建步骤。

## 做了什么

- **程序化火箭**：118 m / 9 m 两级箭体。一级 21 台甲烷发动机（内圈 3 +
  中圈 8 + 外圈 10）、4 片栅格舵、4 条着陆腿；二级 3 台海平面 + 3 台真空
  发动机（加大膨胀比喷管，入轨后羽流自动膨胀）。全部对象按契约命名
  （`engine-s1-` ×21、`engine-s2-sl-` ×3、`engine-s2-vac-` ×3、
  `gridfin-` ×4，共 31 个，子对象无重复前缀）。部件树 48 个节点，
  `listParts()` 返回 `{id, name, parent, object3dName}`。
- **拆解系统**：一键分级爆炸（级间段上浮、二级整体抬升、发动机群下沉、
  栅格舵/着陆腿径向外抛，带连接线）；`explodePart(id)` 单件拆解，
  容器部件（如 `stage1`、`s1-engines`）会递归散开子部件。爆炸偏移与
  飞行位置解耦——飞行中拆解也正确叠加。
- **部件讲解**：8 个热点圆点（跟随投影、背面剔除）+ 点击箭体任意部位 +
  左侧部件目录树，均可打开部件面板：名称、规格、设计理由，可聚焦、
  可就地拆解。选中部件有脉冲线框光环。
- **发射演示**：确定性任务剖面（所有状态都是 `t` 的纯函数，可拖时间轴
  回放任意一秒）：T-8 倒计时 → 点火喷水 → 升空 → MAX-Q → T+160 s
  热分离（二级先点火再脱开，约 70 km）→ 一级翻转返程点火 → 弹道滑行
  → 栅格舵展开 → 再入点火 → 着陆腿展开 → 着陆点火 → 触地回发射台；
  同期二级加速入轨（SECO）。羽流、点火闪光、水汽、滚烟、RCS 脉冲、
  触地尘均为程序粒子。HUD 实时遥测 `{t, altitudeKm, velocityMs, stage}`，
  分离后 stage=2。`setTimeScale(k)` 到 120×。
- **相机**：5 个契约机位（overview / stage1_engines / stage2 /
  gridfin_closeup / launch_pad）+ 滚动驱动的自动运镜 + 发射追踪运镜
  （离台仰望 → 环绕追逐 → 分离同框 → 下降跟拍 → 着陆英雄机位）
  + OrbitControls 手动环绕（点击部件自动聚焦）。`setView` 立即停止
  自动运镜供截图。
- **世界**：程序化天空 shader（白昼 → 爬升渐入太空：星空、大气蓝边、
  暮色带）、地面 canvas 贴图（发射坪标线、道路、A-9 标识）、发射架
  塔楼（桁架+吊臂）、4 杆泛光灯（真实点光源）、推进剂球罐区、
  程序化云层、UnrealBloom 后处理、PCFSoft 阴影。
- **页面**：首屏 / 参数（滚动进入时箭体自动爆炸分解）/ 发射演示
  （飞行剖面 canvas 图 + 任务时间轴 + 倍速）/ 复用流程（步骤卡可点击
  跳转到对应任务时刻）/ 行动号召。1920×1080 与 390×844 均验证，
  控制台零报错。

## 自加的交互（评测契约之外）

1. **可拖拽任务时间轴**：整条任务弧线（点火→分离→回收→入轨）是一个
   确定性的纯函数时间剖面，拖到任意一秒，火箭、粒子、遥测、相机全部
   瞬时重构到该状态——把「发射直播」变成「可反复解剖的任务记录」。
   **它帮用户理解**：一级回收不是瞬间动作，而是一串有严格时序的机动
   （翻转、返程、再入、着陆点火各占哪一段一目了然）。
2. **飞行剖面活图表**：`canvas` 绘制的 S1/S2 高度-时间剖面随飞行实时
   点亮当前位置，分离点有虚线标注。
3. **飞行态遮罩**：发射进行时，覆盖在 3D 画面上的大面板自动淡出
   （HUD 与时间轴保留），让位给火箭主体；结束后恢复。
4. **程序合成引擎音浪**：WebAudio 振荡器+噪声合成的低频轰鸣，随油门
   开度起伏（导航栏喇叭开关，默认关）。
5. **胶片颗粒层**：CSS+canvas 生成的细颗粒覆盖，压暗 UI 与 3D 的
   交界，让网页读起来像一段发布会影片。

## 已知取舍 / 未完成

- 视觉高度是戏剧化映射（箭体世界坐标 ≠ 遥测公里数），遥测严格按
  任务表数值；入轨段高度为风格化演示值。
- 一级着陆点就在发射台原位（叙事选择：回收到发射架上），未做独立
  着陆场。
- 移动端拆解视图受屏幕限制，火箭位于卡片层后方，主要靠透明度透出；
  完整拆解体验以桌面为准。
- `_dev/` 是开发期 Playwright 自检脚本与截图，非交付内容，可忽略。

## 建议的看点

1. 滚动到「飞行器」区：箭体自动分解，点栅格舵 / 真空发动机看面板。
2. 「发射演示」按点火，或直接把时间轴拖到 160 s 看热分离、拖到
   415 s 看一级着陆——全程可 20×。
3. `__bench.setView('stage1_engines')` 仰视 21 台发动机阵列。
4. 分离后留意天空：白昼 → 星空 → 大气蓝边的渐变是随遥测高度驱动的。
