# 盐屿堤道 · 末班信使 — The Last Courier, Saltmarsh Causeway

一只巨大的盐屿鹈鹕，在黄昏的防波堤上骑一辆公路车，去送今天最后一封信。
喉囊里装着要送出的信，翅膀搭在车把上，蹼足踩在踏板上，海风把围巾吹向身后。

**入口：`pelican/index.html`** —— 在 Chrome 里双击就能运行，不需要起服务器，断网也能跑。

---

## 怎么运行 / 怎么看

- 双击 `pelican/index.html`（或拖进 Chrome）。加载约 2 秒（贴图全部在运行时逐像素生成）。
- 左键拖动 = 转动镜头；滚轮 = 缩放。
- 底部按钮切换六个机位（侧面 / 正面 / 3-4 侧 / 俯视 / 头部 / 腿部）。
- 「声音」按钮开启 WebAudio 合成音景：海风、浪声、链条咔哒、海鸥、车铃（需一次点击，满足浏览器自动播放策略）。
- 想直接看某个机位：地址栏加 `?view=side`（可选 `three_quarter / front / top / closeup_head / closeup_legs`）。
- 调试参数：`?debug=1` 显示 GPU 与帧率，`?frames=2` 只渲染两帧，`?post=0` 关闭后期链。
- 自检：`powershell -ExecutionPolicy Bypass -File pelican\verify.ps1`（查文件、查 JS 语法、查 `window.__bench` 契约）。

`pelican\shots\` 里是六个机位的实拍预览图。

## 我做了什么

**结构（这是底线，我按机械关系逐条对过）**

- **脚真的踩在踏板上**：两只蹼足不是摆拍。每帧先从曲柄算出踏板的世界坐标，再用两骨 IK
  （股骨 0.40m + 跗跖 0.55m，膝关节向后折，符合鸟的关节方向）解出跗关节，蹼足贴在踏板
  平台上并随踏板一起翻转。
- **翅膀真的搭在车把上**：肩—肘—腕的翼骨向前下方伸出，短初级飞羽在腕部卷成一个拳头，
  正好箍住两侧的皮革车把；长初级飞羽铺成翼的后缘，沿体侧向后展开。两只翅膀是左右对称的，
  中间夹着黄铜头灯。
- **自行车是一辆真能骑的车**：700C 轮径 0.666m、轴距 0.97m 的菱形车架，前叉带 rake、
  五通、后上叉、后下叉、勾爪、22 根交叉编法辐条、花鼓、飞轮、44 齿盘、18 齿飞轮、
  真正闭合的**链条路径**（外公切线 + 两段包角，链节沿路径按链速流动）、
  曲柄与水平踏板、坐垫与坐管、把立与上扬车把、后挡泥板、黄铜车铃与前灯。
  轮的角速度由车速推出，曲柄角速度再由飞轮/链盘比推出，三者互相自洽。

**画面（全部代码生成，零外部资源）**

- 天空是自写的球面着色器：地平线暖橙 → 天顶深蓝，程序化云带，太阳圆盘与光晕；
  海面是另一支着色器：多层正弦叠加出的法线、菲涅耳、太阳碎光路径、按距离融进雾里。
- 贴图全部是 Canvas 逐像素画出来的：沥青（含裂缝、补丁、中线虚线）、混凝土、沙地、
  皮革缝线、木纹、羽面凹凸、喙的渐变、喉囊、棕边胎（胎面黑、胎侧棕的窄带）、
  信封与邮戳、云、尘点、马兰草。
- 远景：环状远山剪影（噪声驱动的山脊线）、灯塔与旋转光束、远处海鸥、浮尘、
  电线杆与悬垂电线、防波堤栏杆、路边反光桩、待收信的邮筒。
- 后期是自写的一条链：HDR 目标 → 亮部提取 → 两次分离高斯 → 合成
  （ACES 色调映射、暖冷分离调色、暗角、胶片颗粒、边缘色差）。不是 Three 的 EffectComposer。

**声音**：WebAudio 实时合成——滤波噪声做海风与浪，链轮每半圈触发一次金属咔哒，
偶发海鸥叫，开场一声黄铜车铃。

**世界在动**：车不前进，是路在跑——路面贴图 UV 滚动、电线杆/草垛/礁石/邮筒越过镜头后
循环到前方，所以画面有真实的相对运动。

## 最想让你多看两眼的地方

1. **`view=side`（侧面）** —— 逆光剪影版。太阳压在画面左上角的海面上，鹈鹕的喙、喉囊、
   垂下的翅后缘全部镶了一圈金边，车把上那只攥紧的"拳头"正对着头灯。这是全片最像海报的一张。
2. **`view=closeup_legs`（腿部）** —— 凑近看蹼足：三个前趾加蹼膜压在踏板平台上，
   跗关节向后折的弯折清清楚楚，另一条腿正抬到行程最高点。
3. **`view=closeup_head`（头部）** —— 虹膜的金环、眼神光、喙脊、喉囊口露出的一封带邮戳的信。
4. **正面机位** —— 两翼对称地握住车把、头灯在中间亮着，那只红邮筒正好出现在路的前方。

## 已知不足 / 没做的事

- 没有做人物/文字贴图之外的花体字与更精细的羽片排布；翼面是程序化分层羽片，
  放大看仍能看出重复。
- 鹈鹕的体量偏"巨鸟"，这是刻意的（比真实鹈鹕大一圈），但也因此和公路车形成了
  一种略带荒诞的比例——这是风格选择，不是比例失误。
- 声音默认关闭（浏览器自动播放策略），需要点一次「声音」。
- `pelican\shots\` 里的两张 `test_*.png` 是早期调试截图，内容与 `view_side` /
  `view_three_quarter` 相同，仅作占位。
- 本机验证环境的后台浏览器会冻结渲染进程（首屏偶发停在加载提示），
  因此我改用定时器驱动渲染循环 + 墙钟计时的机位转场，保证在低帧率下也能准点到位。
