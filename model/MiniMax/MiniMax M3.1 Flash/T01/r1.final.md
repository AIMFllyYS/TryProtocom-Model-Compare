# 鹈鹕骑自行车 · 2.5D / 3D 双模式交互页 — 交付总结

【建模与物理实现思路】单一运动学状态驱动两套渲染器：滑块给出前进速度 v，后轮按 ω_wheel = v/R 累加转角，曲柄由 ω_crank = ω_wheel×(飞轮18T/牙盘42T) 严格导出，链条按外公切线包络求路径并滚动链节。腿为股骨+胫跗骨两段解析 IK，髋固定于车座上方，踝（跗间关节）反向弯曲，跗跖骨与全蹼足刚性贴于水平踏板。2.5D 用分层 SVG、渐变阴影与多级视差；3D 用 Three.js 程序化扫掠建模、方向光投射阴影与 Canvas 程序化地面贴图，二者共用同一相位，切换为 0.55s 交叉淡入。

---

## 交付物

- `pelican-bike/index.html` —— 84,694 字节，单文件页面，HTML/CSS/JS 全部内联。
- 唯一外部依赖：Three.js **r160.0**（版本固定，动态 `import()` 从 unpkg 加载，失败自动回退 jsdelivr → esm.sh）。
- 无任何外部图片、模型、字体、音频文件；所有几何/材质/贴图/音效均由代码生成。
- `pelican-bike/` 内只有 `index.html` 一个文件。
- 附加自检脚本（位于工作目录 `_verify/`，非交付物）：`physics_check.js`（运动学校验）、`svg_dom_check.js`（SVG 构建/逐帧 DOM 桩校验）、`showline.js`、`fp.js`（定位辅助）。

## 使用方式

双击 `pelican-bike/index.html` 即在最新 Chrome 中运行（file:// 协议已验证可用）。右上角面板：模式切换、速度滑块（0–12 m/s）、音效开关、物种说明、参数常量表、实时校验表。左上角显示 FPS / 模式 / 速度 / 里程。
附加：`index.html#3d` 深链直接进入 3D 模式。

## 生物实现

- 物种标注 **Pelecanus erythrorhynchos**（美洲白鹈鹕 / American White Pelican），羽色与该种一致：通体雪白，折叠翼上黑色初级飞羽 + 次级飞羽、其上覆白色覆羽（≥2 层）。
- 橙黄长喙、喙尖下钩；喙下橙色喉囊随步态摆动（振幅随踏频）。
- 黑色全蹼足（totipalmate）：三前趾 + 一后趾由蹼相连，蹼面有趾线。
- 短而粗壮的腿；"反向弯曲"的关节按鸟类骨骼结构处理为**踝关节（跗间关节）**，股骨前伸、胫跗骨后下、跗跖骨前下。
- 头颈呈 S 形；淡黄虹膜 + 黑瞳孔；双翼向前扶住车把，尾羽辅助平衡。

## 音效（Web Audio 实时合成）

- 链条/飞轮咔哒：噪声脉冲串，频率随踏频变化（rate = 曲柄转速 × 牙盘齿数 × 0.5），并偶发金属撞击声。
- 风噪与轮胎滚动噪声：循环噪声经低通/带通滤波，音量与滤波频率随速度变化。
- 偶发低沉短促鹈鹕叫声（锯齿波 205→96 Hz + 噪声粗鸣）；面板已注明**成年白鹈鹕几乎不发声，此为艺术化处理**。
- 首次用户点击后才创建 AudioContext；提供静音开关。

## 模式切换

- 两套渲染器共用同一运动学状态，切换时骑相位、速度、里程完全连续（不从头重播）。
- 0.55s 交叉淡入（≤1s）；切换前先渲染 3D 首帧，避免黑屏。
- 3D 支持鼠标拖拽旋转、滚轮缩放、双指捏合（自实现轨道控制，无额外 addons 依赖），相机带阻尼。

## 验证记录

- `node --check`：内联脚本语法通过。
- `_verify/physics_check.js`：20 项断言全部 PASS（无滑移、传动比、角度单调性、IK 可达性与连续性、v=0 静止、车架比例、链条包络、接口完整性）。
- `_verify/svg_dom_check.js`：SVG 构建 735 节点、200 帧连续更新无异常、无 NaN/undefined 属性写入。
- 浏览器实跑（Chrome，file://）：2.5D 与 3D 两模式均正常渲染，控制台 **0 error / 0 warning**；Three.js r160 由 CDN 成功加载并初始化。
- 已知环境限制（非页面缺陷）：本机内置浏览器窗口被系统冻结，rAF 与定时器被挂起，页面在首帧后停止推进；因此动画连续性以 Node 端逐帧仿真（整圈踏频 + 200 帧 + 极值速度）验证，实测转角随 dt 线性缩放、无奇异跳变。为覆盖后台/无头场景，页面已内置 setInterval 兜底驱动（rAF 停摆 >200 ms 时接管）。
