# Tempo — 产品介绍动画 · 交付说明

## 交付了什么

| 文件 | 说明 |
|---|---|
| `tempo-promo/index.html` | 成片页面。1920×1080 / 30fps / 15.0s。单文件、零依赖，双击即可打开。暴露 `window.__hf = { duration: 15, seek(t) }`。 |
| `tempo-promo/tempo-promo.mp4` | 可选导出。用无头 Chrome 逐帧 `seek(t)` 抓图后经 ffmpeg 编码，H.264 / yuv420p / 451 帧 / 1920×1080。**刻意不含音轨**（见下）。 |
| `FINAL_MESSAGE.md` | 本文件。 |

工作目录里另有 `.build/`（自检用的抓帧脚本与中间产物），不属于交付内容。

## 怎么跑 / 怎么验

* 直接用浏览器打开 `tempo-promo/index.html`。
* 按 **空格** 播放/暂停（会同时播放 `../assets/bgm.wav`），按 **M** 静音切换。默认不自动播放、不发声。
* 机器验收方式：
  ```js
  window.__hf.duration            // 15
  window.__hf.seek(7.5)           // 同步渲染出第 7.5 秒的确定画面
  ```
  `seek(t)` 完全同步：所有随机数来自固定种子的 mulberry32，噪声纹理与星场在加载时一次性生成，之后每帧只是 `t` 的纯函数，不依赖 rAF / Date.now()。

## 创意

一句话：**把「节奏」做成一个可以看见、会走针的环形笔触**，再让这一个环从被打碎、被重排，一直演化成计时盘、数据环、两个人的同心，最后回到品牌标识。

七个场景严格踩在 `beats.json` 的重拍上（120 BPM，每 2 秒一个 downbeat），所以每一次转场都落在鼓点上：

| 时间 | 字幕 | 画面 |
|---|---|---|
| 0.0–2.0 | 总是被打断？ | 冷调。破碎的虚线核心在努力维持，通知卡片从四面撞进来，每次撞击都把核心震成碎片。背景是不断飘过的消息流。 |
| 2.0–4.0 | 试试 Tempo。 | 混沌在一次重拍上坍缩成秩序：飞散的尘埃收拢成同心晶格，中央浮现 Tempo 标识——一圈**粗细随节拍跳动的环形笔触**，加一根节拍器指针。 |
| 4.0–6.0 | 一键开始专注。 | 标识向观众推近成一具 25 分钟计时盘；一次「点击」从中心激起涟漪，25 根分钟刻度被点亮波唤醒，`25:00` 浮现。 |
| 6.0–8.0 | 25 分钟，只做一件事。 | 尘埃坍缩成**一个**光点（12 点方向，带星芒），时间从这一点开始流动：金弧扫过 25 根刻度，倒计时压缩成 2 秒走完 25 分钟，最后落一个手写勾。 |
| 8.0–10.0 | 数据告诉你，时间去了哪里。 | 计时盘裂成数据环：52% 深度工作 / 21% 会议 / 14% 消息 / 13% 其他，带引线标签、极坐标网格、24 小时分布条与「本周专注 4h 12m」。 |
| 10.0–12.0 | 和朋友一起，专注更久。 | 拆成两颗心：一枚金环（24:18 共同专注）、一枚玫红环（朋友），两者同拍呼吸，中间的光丝有光包往来，环上多出一段虚线「+ 8 MIN TOGETHER」。 |
| 12.0–15.0 | Tempo —— 找回你的节奏。 | 两个节点合流回中心，镜头拉远，透视地平线升起，标识与 TEMPO 字标逐字点亮，最后一个重拍上绽放一次光晕。 |

**贯穿全片的主线**（这是「不突兀」的关键）：中央那一个环从未真正消失，只是不断变形；每个场景边界都由重拍上的冲击波圆环接住；底部那条随时间走动的节拍标尺和右上角时码让整支片子像一件被拍下来的作品，而不是七个片段。

## 技术

* 纯手写 HTML + Canvas 2D，**没有用任何动画/视频框架，没有 CDN，没有网络字体**（A 组条件）。
* 画面素材 100% 由代码生成：程序化 fbm 星云、值噪声胶片颗粒、散景、晶格星场、矢量图标、字标。
* 字幕用 canvas 绘制（每句一行、不自动换行，中文在上、英文在下），并在 DOM 里保留了一份同文案的隐藏文本层，方便检索；文案与 beats 数据内嵌在 HTML 里，因为 `file://` 页面无法 fetch 本地 JSON。
* 字体用系统字体栈（中文 Microsoft YaHei / PingFang SC，拉丁 Segoe UI / Inter），数字用等宽字形绘制以免跳动。

## 自检结果

* ✅ `duration = 15`，canvas 实际 1920×1080。
* ✅ **确定性**：在打乱调用顺序、重复 seek 之后，8 个探测点（0 / 2.5 / 5 / 7.5 / 9.25 / 11 / 13.4 / 15）的截图哈希与首次完全一致。
* ✅ 无 console 报错、无异常。
* ✅ 7 条文案逐字出现在 DOM 中，顺序与 `copy.md` 一致。
* ✅ 451 帧全部抓取成功并合成 MP4。

## 没做的 / 需要你知道的

1. **MP4 是无声的**。按约定评测方会从第 0 秒把 `assets/bgm.wav` 混进成片，如果我自己再烤一条音轨就会重音。页面本身已经接好了 `../assets/bgm.wav`（默认静音、空格播放），本地看片时按空格就有音乐。
2. **没有做音频跟随**。视觉上用了 beats.json 的节拍点和 120 BPM 的节奏骨架，但音频是外部混入的，我没有做任何频谱/响度匹配。
3. `.build/` 里残留了约 1.1 GB 的抓帧 PNG 和 Chrome 用户目录，我尝试清理，但沙箱的删除工具拒绝操作本工作目录（判定在工作区之外）——这些是中间产物，手动删掉即可，不影响交付。
4. 字体依赖系统字体栈：在没装中文字体的 Linux 机器上，中文会变豆腐块（Windows/macOS 正常）。

## 最想让你看的地方

* **6.0–7.6 秒**：尘埃坍缩成「唯一的那一点」，金色时间从那一点开始流走——这是全片的题眼。
* **2.0–4.0 秒**：混乱收束成节拍晶格、标识诞生的那一下。
* **12.0–15.0 秒**：地平线升起与最后的重拍绽放。

用时约 55 分钟（含抓帧、逐帧自检与 MP4 编码）。
