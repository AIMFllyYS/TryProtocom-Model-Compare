# 任务：鹈鹕骑自行车 —— 2.5D / 3D 双模式交互页面

## 交付物
- 在当前工作目录下新建文件夹 `pelican-bike/`，其中只包含一个文件 `index.html`。
- 所有代码（HTML/CSS/JS）内联在该文件中。唯一允许的外部依赖是从 CDN 加载的 Three.js（r150 及以上，可附带其官方 addons，例如 OrbitControls），版本必须固定。
- 不得引用任何外部图片、模型（glTF/OBJ）、音频文件或字体。所有几何、材质、纹理与音效都必须用代码生成。
- 在最新版 Chrome 中双击打开即可运行，控制台不得出现报错。

## 核心场景
一只鹈鹕骑着一辆自行车，在地面上持续前进，镜头或场景循环滚动。

## 模式一：2.5D（SVG）
- 用内联 SVG 绘制，采用侧视或 3/4 视角，通过分层、渐变、阴影营造纵深感。
- 鹈鹕与自行车的各部件是独立的 SVG 元素，由 JS 驱动动画，不能是一张静态图。

## 模式二：3D（Three.js）
- 用 Three.js 程序化建模，并带有光照与阴影（至少包含一个投射阴影的光源和一块接收阴影的地面）。
- 支持鼠标或触控旋转、缩放视角。

## 模式切换
- 页面上有明显的切换按钮。切换时两种模式保持同一动画状态，包括骑行相位和速度，不从头重播。
- 需要有平滑的过渡效果，时长不超过 1 秒。

## 物理准确性要求
1. 车轮滚动无打滑：车轮角速度 × 车轮半径 = 前进速度。
2. 传动比一致：曲柄转速与后轮转速之比等于后飞轮齿数与牙盘齿数之比，齿数在代码中定义为常量。
3. 踏板保持水平或接近水平，不随曲柄一起旋转。
4. 腿部为两段式运动链（大腿 + 小腿），用逆运动学（IK）计算关节角度，脚始终贴合踏板，髋部固定在车座附近。
5. 车架几何合理：轴距、车座高度、车把位置与车架尺寸比例协调。
6. 提供速度滑块（0 到最大值）；速度为 0 时，所有运动部件静止。

## 生物准确性要求
1. 物种明确：在页面标注物种学名（例如 *Pelecanus occidentalis* 或 *Pelecanus erythrorhynchos*），羽色与该物种一致。
2. 长喙，喙尖带钩，下喙带可见的喉囊（gular pouch），喉囊在运动中轻微摆动。
3. 足为全蹼足（totipalmate），四趾均由蹼相连。
4. 腿短而粗壮；鸟类“反向弯曲的关节”实为踝关节，关节位置须符合鸟类骨骼结构。
5. 翅膀用来扶车把或保持平衡，羽毛分层至少体现初级飞羽、次级飞羽、覆羽中的两层。
6. 头颈呈 S 形姿态，眼睛位置与颜色符合所选物种。

## 音效要求
- 全部使用 Web Audio API 实时合成。
- 至少包含：链条与飞轮的咔哒声（频率随踏频变化）、轮胎摩擦或风噪（音量随速度变化）、偶发的低沉短促鹈鹕叫声（成年鹈鹕基本不发声，可在说明中注明艺术化处理）。
- 用户首次点击后才创建并启动音频，并提供静音开关。

## 性能与界面
- 两种模式在普通笔记本上都能稳定运行在约 60 FPS，角落显示 FPS。
- 控件：模式切换、速度滑块、音效开关、物种与参数说明面板（列出传动比、轮径等关键常量）。
- 响应式布局，窗口缩放时画面不变形。

## 评测接口（必须实现）
```js
window.__bench = {
  setMode(m),          // '2.5d' | '3d'
  getMode(),
  setSpeed(v),         // 前进速度，米/秒
  getState() → {
    mode, speed,              // 当前模式与速度（m/s）
    wheelAngle, crankAngle,   // 后轮、曲柄的累计转角（弧度，单调累加，不取模）
    wheelRadius,              // 米
    chainringTeeth, cogTeeth, // 牙盘、飞轮齿数
    pedalAngles: [l, r],      // 左右踏板平台相对地面的倾角（弧度）
    footToPedal: [l, r],      // 左右脚接触点到踏板中心的距离（米）
    hipToSaddle               // 髋关节到车座的距离（米）
  },
  species                     // 学名字符串
}
```
3D 模式下另外暴露 `window.__scene`（THREE.Scene）和 `window.__renderer`（THREE.WebGLRenderer）。
