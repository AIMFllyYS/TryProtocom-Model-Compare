# 曙光圣殿 · Basilica of the Captured Dawn

**一座为"被封存的最后一缕晨光"而建的漂浮圣殿**——环形山浮岛悬于云海之上，希腊十字平面的大教堂守护穹顶下的"晨光之核"。黎明时分，低垂的日光从西南洒来，被圣殿永远留住：从此白昼不必再落幕。

## 运行

- 直接用 Chrome 打开 `mc-build/index.html`（`file://` 可用，Three.js r149 已内置于 `mc-build/three.min.js`，无任何外部资源）。
- 或 `cd mc-build && python -m http.server` 后访问对应端口。
- 页面加载后自动开始一镜到底的巡游镜头（穿越云海 → 过桥 → 经前庭 → 入殿 → 升至穹顶晨光之核 → 绕行出画）。

## 操作

- **左键拖拽** 环绕 · **右键拖拽** 平移 · **滚轮** 缩放 · **双击** 聚焦到点击的方块 · **WASD+QE** 漫游
- 底部按钮可切换五个命名视角或回到巡游；`window.__bench.setView(id)` 切视角并暂停运镜。
- `window.__scene`（整个世界）、`window.__renderer`、`window.__voxels`（体素表）均已暴露；`blockSize: 1`。

## 世界里有什么（全部代码生成）

- **天空浮岛**：噪声塑形的高原+倒悬锥体，岩唇、垂藤、钟乳石，岩层随深度由石转黑曜岩。
- **大教堂**（约 36 万方块中的主体）：
  - 八角形中殿 + 双耳室 + 后殿 + 希腊十字四臂；
  - **穹顶**：16 肋金色穹顶 + 钟形天窗（oculus）+ 鼓座 16 窗 + 顶部塔亭；
  - 四角钟楼（钟室发光窗、饰条层线、金顶）、立面玫瑰窗（含石制辐条棂）、门廊双柱+三角楣、飞扶壁落在附楼屋顶的墩柱上；
  - 外立面：深色基座层、隅石、盲壁柱节奏、横饰带、旗帜徽记。
- **可进入的内部**：棋盘大理石地面 + 青金石穹顶（金星点缀的天穹拱顶）+ 后殿蓝色星空半穹顶 + 日晷式马赛克地板勋章 + 木长椅、烛列、唱诗席、祭坛、**金色圣体光（sun monstrance）**、管风琴楼厢、侧礼拜堂、吊灯链、**悬浮于穹顶之下的"晨光之核"**（金壳包裹的光球 + 环绕的运转金环 + 天光柱 + 尘埃粒子）。
- **前庭**：反射池（青金石底）、方尖碑圣火、四尊带翼守卫雕像、花坛法绣花园、日纹马赛克地面、栏杆灯柱。
- **石桥 + 门岛**：大跨拱桥连向卫城小岛（塔门、灯、小径）。
- **氛围**：程序化黎明天空 shader（日轮+地平线橙红渐变为靛紫）、体积光柱（菲涅尔衰减 shader）、瀑布+水雾、漂移云层、悬浮岩屑、上升天灯、火星、流萤、绕穹飞鸟。

## 技术

- 体素逐面剔除 + Minecraft 式**顶点环境光遮蔽** + 逐面亮度抖动；按材质分桶合并成 32×32 分块 BufferGeometry。
- 贴图图集全部由 Canvas 程序化绘制（约 44 种原创材质：砂岩/大理石/金/琉璃彩窗/天青石/陶瓦/草地/水晶/符徽等），瓦片带外扩边缘防止 mipmap 渗色。
- ACES 色调映射 + PCF 软阴影 + 半球光 + 多盏点光（圣坛/中殿/后殿）+ 加法混合光晕精灵。
- 实测约 **36.4 万体素、~60fps、控制台零报错**。
