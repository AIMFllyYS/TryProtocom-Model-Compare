# Tempo 产品介绍动画（A / C 两组）

> 同一份任务跑两组，只有“条件”不同。A 组环境里没有任何动画 / 视频相关 skill，且不得执行 `npx skills add`；C 组预装固定版本的 HyperFrames 及其官方 skills。两组产出都由评测方用同一渲染器重新渲染后评分。

## 契约

- 文案在 `assets/copy.md`（每行一句字幕，中文 | English，按顺序使用），音乐是 `assets/bgm.wav`，节拍时间点在 `assets/beats.json`。产品是虚构的专注计时 App「Tempo」，不需要上网调研。
- 成片 1920×1080，30fps。时长不限，推荐约 15 秒（`assets/bgm.wav` 的长度），多了少了都可以。评测方会把 `assets/bgm.wav` 从第 0 秒起混入，所以请不要自己剪辑这份音乐；成片比音乐长时，超出部分没有评测音乐，需要的话请用 Web Audio 自行生成声音。
- 字幕中英双语，每句只占一行，过长就拆成多条，不要自动换行。
- 画面里的素材只能来自 `assets/` 和你用代码生成的图形。
- 在工作目录下新建文件夹 `tempo-promo/`，入口是 `tempo-promo/index.html`，页面必须暴露：

```js
window.__hf = { duration, seek(t) {} };   // seek(t) 同步渲染出第 t 秒的确定画面
```

  评测会逐个时间点调用 `seek(t)` 截图，所以时间不能由 requestAnimationFrame 或 Date.now() 驱动，随机数用固定种子。
- 如果你也导出了 MP4，可以一并放进来（不强制）。
- 完成时写 `FINAL_MESSAGE.md`：交付了哪些文件，只写真实存在的内容。

## 条件

【A 组】不使用任何 skill，也不使用视频框架（包括 HyperFrames、Remotion）。手写 HTML、CSS、JS。动画库可以从 CDN 加载（固定版本）。

## 愿望

我想要一支“看了会想再看一遍”的 Tempo 产品动画。推荐时长约 15 秒，但多一些、少一些都没有问题，时长由你根据内容决定。

视觉风格、色彩、版式、运动性格、有没有叙事、几个场景、什么节奏，全部由你自己分析和决定，我不指定任何风格。

同时，无论是 JavaScript、WebGL、Three.js 还是什么各种技术都可以，用你最大的努力，我希望：

1. 作品本身视觉是惊艳的、艺术性顶尖的。
2. 内容本身是高级的、有深刻含义的。
3. 转场、画面（或镜头、场景、交互）之间的衔接是自然的：可以一镜到底，或者至少画面和画面之间有主线、不突兀。
4. 从观众的视角感受到的是大师之作，并且震惊这竟然是用代码生成的。
5. 可以不限 token，尽可能炫技。
