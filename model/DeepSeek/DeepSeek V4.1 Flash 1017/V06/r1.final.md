# THE INTERVAL — 为太阳造的一间暗室

> 一座立在高荒漠盐碱地上的混凝土光室。它存在的理由只有一个：在至日，接住最后一束光。

这是本次运行的最终说明。所有内容都是真实的：下面的每个技术点都可以在 `photoreal-building/` 的代码里找到。

---

## 运行方式

- 入口：`photoreal-building/index.html`
- 直接用 Chrome 双击打开即可（`file://`），不需要服务器、不需要联网。
- 需要支持 WebGL2 的浏览器；首次打开会有约 1–2 秒的纹理烘焙/环境光烘焙，随后画面出现。
- 控制台无报错。用到的唯一外部代码是本地固定的 `vendor/three-0.147.0.min.js`（three.js r147，UMD），不是 CDN、不是运行时下载。

## 五个视角

| 键 | 视角 | 内容 |
|---|---|---|
| `1` | `facade` | 斜前方 3/4 立面：模板混凝土、竖向鳍板、水平引光缝、青铜日晷、反射池 |
| `2` | `street_level` | 人眼高度沿池上步道进入的门洞：暗室、尽端青铜仪器盘、地面与水面反射 |
| `3` | `aerial` | 低太阳角度下的鸟瞰：长影、屋顶、盐碱地、整个场地关系 |
| `4` | `detail` | 西墙上的青铜日晷特写：同心刻度环、5° 刻度、模板木纹、对拉螺栓孔、浅景深 |
| `5` | `dusk` | 黄昏：室内暖光、仪器盘发光、水面倒影、深蓝天空与星点 |

`setView(id)` 后：相机 1.05 s、光照 1.2 s 完成过渡，约 1.3 s 后画面稳定；`dusk` 会同时把天空、太阳高度、雾、曝光、室内灯、水色与星空切到黄昏状态。

## 交互

- 左键拖拽：环绕；滚轮：推拉；右键（或 Shift + 拖拽）：平移；带阻尼。
- 数字键 `1–5` 切视角；`H` 隐藏界面；底部按钮同样可点。
- 任何手动操作都会立即接管镜头，不会和自动镜头“打架”。

## 契约接口

```js
window.__scene       // THREE.Scene
window.__renderer    // THREE.WebGLRenderer
window.__bench = {
  views: ['facade','street_level','aerial','detail','dusk'],
  setView(id),
  listParts()        // 119 个命名构件（id / name / parent）
}
window.__benchReady  // 首帧渲染后为 true
```

页面打开立刻就有画面；`__bench` 在加载早期就存在（带 pending 队列），不会出现“接口尚未挂出”的空窗。

## 技术手段（全部程序化）

- **几何**：约 120 个命名构件，全部由 Box / Plane / Cylinder / Circle / Torus / BufferGeometry 组合生成；世界尺度 UV，使 5 m 混凝土贴图在任何尺寸的墙面上比例一致。
- **贴图**：加载时用 **GPU 烘焙**，每个材质一次性生成 albedo / normal / ORM（AO-Roughness-Metalness）三张图，混凝土为 2048²，其余 512²–1024²。噪声、模板板缝、对拉螺栓孔、锈迹、雨痕、泛碱、骨料、盐壳、泥裂、铜绿、拉丝、青铜刻度等全部是解析 GLSL 函数算出来的，没有一张图片文件。
- **材质**：MeshStandardMaterial（PBR），带世界坐标宏变化着色器（大尺度色差、雨痕、墙脚污渍、顶部积灰），避免贴图重复的机械感；青铜仪器盘单独一套极坐标刻度/高度/粗糙度/金属度贴图；玻璃是自定义菲涅耳 + 立方体环境反射 + 污渍着色器；水面是自定义平面反射 + 程序化波法线。
- **天空与光**：自定义大气/太阳/云/星 shader，同一套函数同时驱动可见天空与 PMREM 环境光（IBL）；黄昏的霞光、云被夕阳照亮、星点都来自这套函数。太阳是方向光（4096² PCF Soft 阴影，按视角收紧视锥），另有一盏无阴影的“反射光”补光与半球光。
- **水**：镜像相机 + 平面反射 RT + 裁剪平面（只渲染水面以上），波纹扰动用解析波函数；池底、池壁、走桥、黄铜梁、倒影都参与。
- **后处理**：HDR 半浮点 → SSAO（12 采样 + 深度感知模糊）→ 景深（detail 视角启用）→ 阈值 + 多级降采样/升采样 Bloom → ACES filmic → 分离调色、暗角、胶片颗粒、轻微色差，太阳进画面时的程序化光晕。
- **氛围**：尘埃粒子在门洞光柱里缓慢漂浮；340 个干草丛实例（交叉面片 + 风摆着色器）；远处 6 只飞鸟；盐碱地/砂砾/混凝土/池沿的尺度与磨损细节；地面伸缩缝、屋顶女儿墙、通风管、雨落管、门把手、铭牌等。
- **字体**：只用系统字体（Georgia / 系统无衬线），没有字体文件。青铜铭牌上的铭文是加载时用 Canvas 2D 画出来再生成法线的，没有外部文字文件。
- **性能**：在 1600×900、RTX 5060（ANGLE / D3D11）上实时；内置自适应分辨率——如果前 2.5 秒帧时长偏高会自动降采样，弱一些的机器也能跑。

## 没做完 / 取舍

- 玻璃是近似（菲涅耳反射 + 脏污 + 透明度），没有做真实折射与色散；远处室内反射也没有 SSR。
- 体积光是近似的：门洞光柱靠尘埃、太阳照亮的地面与 Bloom 表达，没有做屏幕空间体积散射。
- 水面是平面反射，不是 SSR；波纹是解析波，不是流体模拟。
- 黄昏室内是布光近似（点光 + 聚光 + 自发光灯槽），不是光能传递。
- 没有声音：按契约不携带音频，也没有运行时合成。
- 出于性能，阴影只在方向光上；小物件（铜铭牌、拉手、草）不投影。
- 未使用任何图片、HDR、模型、字体或音频文件；全部几何、材质、贴图、光照都是代码在运行时生成的。
