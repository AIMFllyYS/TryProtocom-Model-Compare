# ATELIER No.07 — 破晓 / DAYBREAK

一辆定制的钢架全路况自行车，停在一间只有黎明前那一小时才会亮起的工坊里。  
它不带任何外部图片、模型、音频或字体文件：车架、轮组、传动、皮革、轮胎、尘埃、光线、声音、排版——全部在浏览器里由代码当场生成。

入口：`bicycle/index.html`  
双击用 Chrome 打开即可（`file://` 直接运行，不需要服务器）。Three.js r149 已放在 `bicycle/lib/three.min.js` 本地，断网也能打开。

---

## 这辆车

- **车种 / 设定**：1×11 钢架 all-road，700×38c 黄边胎，液压碟刹。
- **几何**：轴距 1000 mm，后下叉约 421 mm，BB drop 70 mm，头管角 73°，座管角 73.5°，前叉 offset 约 34 mm。
- **传动**：48T 牙盘 × 16T 飞轮 = **3.00**；曲柄 172.5 mm；11 速 11–34T 飞轮；112 节链条。
- **轮组**：28H，前后交叉编法，黄铜条帽，160 mm 中心锁碟片。
- **驾驶关系**：`setSpeed(v)` 后，车轮、曲柄、飞轮、链条、后拨导轮全部按同一套运动学联动：
  - 后轮角速度 = `v / 0.35`
  - 曲柄角速度 = 后轮角速度 ÷ 3.00
  - 链条线速度 = 曲柄角速度 × 牙盘节圆半径
  - 链条由 112 个实例化链节沿闭合路径运动；导轮按链条行程转动。
- **看不到的地方**：座管夹、五通、头管轴承、前后桶轴、刹车油管、变速线、把立、把带缠绕、坐垫铜铆钉、轮圈铜线、车头铜牌、下管 DAYBREAK 贴字、胎侧模压花纹等。

## 场景与画面

- **Atelier 工作室**：暗色圆弧背景、地面微反射、晨光晕、细圆环与刻度、空气尘埃、暖/冷双色轮廓光。
- **材质全部程序生成**：Canvas2D 绘制的混凝土、金属闪粉、3K 碳纹、皮革粒面、把带织纹、轮胎胶料、铜牌与贴字；法律意义上没有任何图片文件。
- **后期**：自建的 HDR 离屏管线——ACES 色调映射、阈值 Bloom、分离高斯、镜头色散、银盐颗粒、暗角与抖动；没有使用 EffectComposer 或任何 addon。
- **倒影**：整车的镜像克隆置于半透明抛光地面之下，形成完整倒影。
- **声音**：WebAudio 程序生成的房间底噪、传动低频与飞轮咔哒声，默认静音，点右侧 SOUND 开启。
- **叙事**：破晓、第一座山、钢会记住每一次弯道。标题、色温、镜头和那圈细线都围绕这个时间点组织。

## 交互

- 拖动鼠标：环绕相机
- 滚轮：缩放
- `1` – `6`：切换六个命名视角（side / three_quarter / top / closeup_drivetrain / closeup_front / closeup_wheel）
- `Space` 或底部 **RIDE**：让车以 5.5 m/s 走起来
- `H`：隐藏/显示界面
- 右侧 SOUND：开关程序生成的声音

## `window.__bench`

已按要求挂载：

```js
window.__bench = {
  views: ['side', 'three_quarter', 'top', 'closeup_drivetrain', 'closeup_front', 'closeup_wheel'],
  setView(id),        // 0.66 s 缓动转场；700 ms 定时器兜底，保证 1 s 内到位
  listParts(),        // 18 个部件，带 id / name / parent
  setSpeed(v),        // m/s
  getState()          // speed, wheelAngle, crankAngle, wheelRadius, chainringTeeth, cogTeeth
}
```

同时暴露 `window.__scene`（`THREE.Scene`）与 `window.__renderer`（`THREE.WebGLRenderer`）。

`getState().wheelAngle` / `crankAngle` 使用墙钟时间积分，只增不取模；即使渲染帧率很低，读数也不会失真。

## 自检记录

用 Playwright + Chrome 在 `file://` 下完整跑过：

- 六个命名视角全部在 1 s 内到位，相机位置与朝向正确；

- 鼠标拖拽 / 滚轮缩放均改变相机；
- 无 console error、无 page error；
- `listParts()` 返回 18 个节点，父子关系完整。

## 已知的取舍

- 这是一台 1×11，打开后拨看得到简化但结构完整的双导轮笼；没有前拨。
- 坐垫、STI 手变头、脚踏是手工雕的程序化近似，不是工业 CAD 数据。
- 地面倒影用镜像克隆实现，而非屏幕空间反射；在光滑地面上足够好看，但不是物理光线追踪。
- 场景为高质量实时渲染设计（约 25 万三角形、500 draw calls 含倒影），建议在独立显卡上观看；软件光栅化也能运行，只是帧率较低。
- 所有文字使用系统字体；没有引用任何字体文件。

如果你只打开一个视角，打开 **side** 或 **three_quarter**；如果你想确认“这是真的一台车”，打开 **closeup_drivetrain**，按空格让它走起来。
