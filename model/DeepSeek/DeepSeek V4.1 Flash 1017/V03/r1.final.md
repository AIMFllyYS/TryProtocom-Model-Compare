# SOL & LUNA — 日月双刃

**这是一支 56 秒的 Minecraft 风格定格短片，实时跑在浏览器里。** 打开 `mc-sol-luna/index.html` 即可播放（Chrome / 双击或用任意静态服务器都行）。没有 MP4：影片由代码当场生成，每一帧都是 WebGL 现场渲染出来的。

---

## 怎么看

- 直接打开 `mc-sol-luna/index.html`。画面自动开始播放，**第一次点击/按键**才启动声音（浏览器策略），右下角有静音开关。
- 想定格看某一帧：`index.html?t=27.5&paused=1`（第 27.5 秒、暂停）。`?scale=1` 可以强制全分辨率渲染（软件渲染环境默认会自适应降到 0.75× 保证流畅）。
- 键盘：`空格` 播放/暂停，`M` 静音，`R` 重头播放；底部有进度条和按钮。
- 给评测脚本的接口都在 `window` 上：
  - `window.FILM = { duration:56, fps:24, poseFps:12, shots:[12 个镜头，与 shot-list.json 完全一致], seek(t), play(), pause(), cameraAt(t), getPose(t) }`
  - `window.__bench = { views:[hero_front, hero_side, hero_back, closeup_face, wide_scene], setView(id), listParts(), hideHUD(bool) }`
  - 另外暴露 `window.__scene`、`window.__renderer`；所有随机数固定种子，`seek` 是纯函数（除少量残余 FX 像素外逐帧可复现）。

## 片子讲什么

三幕，56 秒，12 个镜头、12 台预置摄影机：

1. **I. FORGE（0–21.5s）**：黎明森林，方块铸剑师 Ash 独自在林中空地。他砍树取木、下矿取铁、熔炼、锻打，把**太阳铸成 Sol、月亮铸成 Luna**。两把剑亮起的那一刻，天色转入蓝调。
2. **II. SIEGE（21.5–47s）**：黄昏，村庄钟声炸响。劫掠兽撞破村门，两个卫道士跟进。Ash 挡在村民前面：举剑抗冲撞、跳劈、用 Luna 插地展开月盾救下被打倒的村民；最后在 0.8 秒的静默里，双剑交叉一击。
3. **III. HERO（47–56s）**：黎明。钟声重新响起，村民围拢，交易一颗绿宝石；Ash 把两把剑挂上村门，当作一暖一冷两盏灯。镜头沿大路升起拉远，村庄、森林与日出一起收进最后一帧。

主题是「光不是被给予的，而是被锻造和承担的」：日为攻、月为守，缺一不可——所以最后他把两把都挂在了村门上。

## 技术（全部现场生成，无任何图片/模型/音频/字体文件）

- 几何：地形、树、房屋、钟楼、村门、矿洞、营地道具全部由整数格方块拼装，InstancedMesh 合批；角色与劫掠兽是刚性长方体骨架（头/躯干/双臂/双手/双腿 + 手持挂点）。
- 贴图：每一张像素贴图都在运行时用 Canvas 逐像素画出来（32×32 方块图集、16×16 角色六面图集、剑刃渐变、火焰/光晕 sprite）。角色是原创设计（不是官方皮肤）。
- 光：一盏真实投影太阳/月亮 + 半球光 + 相机侧补光 + 7 盏会随镜头改位的点光（火把、炉火、两把剑、月盾），配合天空穹顶 shader（渐变、日/月盘、星空、云层）、高度雾。
- 后期：自写的 HDR 管线——亮部提取、两次分离高斯模糊、ACES 色调映射、暖冷分离调色、色差、暗角、胶片颗粒、2.05:1 遮幅，全部在 shader 里完成。
- 定格感：输出锁定 24fps，角色姿态只有 **12fps**（每姿态保持 2 帧），摄影机与环境按 24fps 走，两者形成「世界在动、角色在定格」的对比；每个关键动作用「预备—动作—反应—保持」的分解姿势写死。
- 声音：`js/film-audio.js` 是一套纯 Web Audio 合成引擎（振荡器 + 程序化噪声 + 滤波器 + 程序化卷积混响 + 总线压限），58 个具名 Foley cue 与一条随剧情推进的原创配乐时间线；44.9–45.7s 是刻意留白。
- 依赖：只用了固定版本的 three.js r160。优先加载本地 `js/three.min.js`（离线可用），失败才回退到 jsDelivr 的同版本 CDN；除此之外没有任何外部请求。

## 已知不完美（如实说）

- 角色在远景/逆光镜头里偏暗，面部细节读不清；这是 1/16 像素尺度 + 强背光的代价，近景（S05/Luna 救村民）更好。
- 劫掠兽是方块拼的、动作是姿态跳跃式的，冲击力和「真实感」比不了逐帧手 K 的生物动画。
- 软件渲染（SwiftShader）下帧率很低，虽然做了自适应分辨率，播放仍可能掉帧；真实 GPU 上才顺。
- 我没有用耳朵听音频（无法试听），只能确认引擎加载无报错、58 个 cue 全部注册；声音的最终听感未经过人耳验证。
- 部分镜头（S01、S06）是剪影/大远景风格，故事读解依赖字幕辅助。
