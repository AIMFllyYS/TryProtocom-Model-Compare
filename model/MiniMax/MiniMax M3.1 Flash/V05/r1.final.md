# 沙海之仪 · The Orrery of Khaar-Stone

> 日轮坠海三百年后，守仪者于此重修浑天之殿。
> 每一方石、每一道光，皆由代码当场生成。

---

## 一、我建了什么

在干涸海床上重建的一座**观星神殿**——"沙海之仪"（The Orrery of Khaar-Stone）。

它的世界观是一句设定：太阳坠落之后，海水退去，守仪者把 astronomical 观测台重新砌成了一座纪念碑。这座建筑不是一栋房子，而是一台**仪器**：正中央悬着一颗由方块构成的熔融核心，外面套着三道缓慢旋转的金色浑仪环；光从天顶的圆孔（oculus）落下，穿过环轨，落在祭坛上。

### 建筑本体（全部由单位立方体方块砌成，共 8.5 万余块）

从下往上是完整的古典秩序：

| 层次 | 高度 | 内容 |
|---|---|---|
| **大基座 Podium** | 15 层 | 从盐滩里升起的巨型圆鼓，24 根巨柱式壁柱（pilaster）环绕，底部有收分（batter），顶部一圈女儿墙式矮垣 |
| **三层鼓座 Drums** | 各 2 层 | 半径 51 / 44 / 38 的三级叠涩圆台，每层带连续檐口（cornice）与列柱式女墙 |
| **环廊 Ambulatory** | 6 格宽 | 外墙与内拱廊之间的环形走道 |
| **拱廊 Arcade** | 12 个开间 | 12 道真正的阶梯拱券洞，拱脚墩石、拱心石与金色券环都是实打实的方块 |
| **外墙 Rotunda Wall** | 20 层 | 三层厚的石墙，12 扇高窗，窗内有彩色玻璃格（冷暖交替） |
| **穹顶 Dome** | 30 层 | 余弦轮廓的阶梯穹顶，16 道窄肋，顶部金色冠环与**敞开的圆孔** |
| **四座角塔 Towers** | 45 格高 | 位于甲板对角，锥形收分，顶端细长金尖与青色水晶信标 |

### 可以走进去的内部

- **中殿**：直径 30 格的圆形大厅，地面是**程序化拼花**——同心石环、24 道放射状金线、中央八芒星，外圈环廊是另一套配色。
- **四翼厅堂**：从环廊四面的门洞进入——东为**典籍厅**（书架、长案、灯烛、封缄的档案箱），北为**烬火祠**（四座火盆、守仪者铁砧、悬吊金链灯），南为**浑仪室**（地面嵌金同心环、三座小型浑仪），西为**仪典前厅**（双列石柱、鎏金行进带、门侧火盆）。
- **螺旋升阶**：环廊内一道 46 级石阶盘旋而上，通到内拱廊之上的**环形挑台**，从那里可以俯瞰整个中殿。
- **祭坛**：三级圆台 + 深色玄武岩祭坛 + 金色压边 + 四支燔燎烛台。
- **前轴线**：北面一道 31 格宽的**大台阶**直接切穿三级鼓座落到盐滩；接着是 140 格长的**仪式大道**，两侧是引水明渠、灯柱与成对方尖碑，尽头是一座双塔**石门**，门楣分三层。

### 环境

干涸的盐滩上散布着盐柱、废弃的旧神殿石柱与残鼓；四片浅水潭与大道两侧的镜面水渠倒映着落日与建筑；空气中飘着火星与浮尘。

## 二、怎么运行

**直接双击 `mc-build/index.html` 即可**（Chrome / Edge / Firefox 均可，`file://` 协议下正常工作，无需服务器、无需联网）。

```
mc-build/
├── index.html      ← 入口（唯一需要打开的文件）
├── app.js          ← 打包后的运行文件（three.js r160 已内置）
└── src/            ← 全部源码（纯 ES module，未压缩）
```

* three.js **0.160.1** 被 esbuild 打包进 `app.js`，因此**离线可用**（契约允许 CDN，这里选择本地内置以保证 `file://` 打开零依赖）。
* 源码在 `mc-build/src/`：`textures.js`（程序化贴图）、`voxels.js`（体素引擎 + 材质 + 烘焙 AO）、`monument.js`（主体建筑）、`furnish.js`（厅堂陈设 / 仪式大道 / 散置遗物）、`terrain.js`（盐滩与水潭）、`sky.js`（天空着色器）、`env.js`（水面 / 光柱 / 粒子 / 远景）、`core.js`（浑仪核心）、`controls.js`（相机）、`main.js`（装配与后期）。
* 想改代码：根目录 `node build.mjs` 重新打包（`node build.mjs --watch` 可监听）。

## 三、操作方式

| 操作 | 效果 |
|---|---|
| **拖拽** | 环绕模式：绕建筑旋转；漫游模式：转头 |
| **滚轮** | 推拉镜头 |
| **W A S D** | 移动（漫游模式沿视线，环绕模式平移焦点） |
| **Shift** | 加速 |
| **F** | 在「环绕」与「漫游」之间切换 |
| **G** | 漫游模式的重力开关（关闭后可自由飞行） |
| **Space / C** | 上升 / 下降 |
| **1 – 5** | 切换到五个预设视角 |
| **0 或 P** | 开关自动运镜 |
| **H** | 隐藏 / 显示界面 |
| 右侧面板按钮 | 同样的五个视角，外加「自动运镜」与「隐藏 HUD」 |

**漫游模式会与方块实体碰撞**——你走不穿墙体、门洞是真的门洞、台阶是真的台阶，可以一路从盐滩走上大台阶，穿过前厅，穿过拱廊，登上挑台。

打开页面即自动开始一段 210 秒的环绕运镜（12 个关键帧的 Catmull-Rom 样条），不需要点任何东西就有画面；一旦你开始拖拽或按键，自动运镜会暂停。

## 四、给评测的接口

```js
window.__bench = {
  views: ['exterior_far', 'exterior_near', 'aerial', 'interior', 'detail'],
  setView(id) { /* 切到命名视角并暂停自动运镜 */ },
  blockSize: 1,
  blocks: 85632,        // 方块总数
  info: { gpu, software, chunks },
  rig, voxelMap
}
window.__scene      // THREE.Scene，全部方块在名为 'voxel-world' 的分组里
window.__renderer   // THREE.WebGLRenderer
```

`setView` 也可以用 URL 直接进入，例如 `index.html#view=interior`。

五个视角分别是：**远景**（巨构全貌，逆光剪影）、**近景**（台基、穹顶、角塔）、**俯瞰**（平面秩序与仪式大道）、**内部**（中殿与浑仪核心）、**细部**（祭坛与地面拼花）。

## 五、一些自己加的东西

* **逐块烘焙环境光遮蔽**：用经典体素角点 AO 算法（side1/side2/corner）算出每个方块的遮蔽值，作为实例化属性注入着色器，凹角自然变暗——这是让方块世界"看起来像石头"而不是"贴图方块"的关键。
* **按材质分块实例化**：每种材质按 34 格空间分块生成独立 InstancedMesh 并计算包围球，视锥剔除真正生效（单一巨型 InstancedMesh 每帧都得画全世界）。
* **手写天空**：天顶靛蓝 → 地平线余烬橙的梯度、低悬的日轮与光晕、两层缓慢漂移的云带、按方向 hash 出来的星场、以及抑制色带的抖动。
* **自写水面着色器**：三层正弦叠加的波纹法线、菲涅耳混合程序化天空、对巨型圆筒做解析求交得到的神殿倒影、以及日轮的高光。
* **自写后期**：HalfFloat 渲染缓冲 → UnrealBloom → 自写的 ACES 色调映射 + 分离色调 + 暗角 + 胶片颗粒 + sRGB 编码，最后一遍出画。
* **自适应画质**：启动后测量帧率，若低于 16 fps 会自动降低渲染分辨率、关闭阴影、缩小辉光分辨率，保证在软件渲染的机器上仍然可以操作。
* **原创贴图**：石灰岩、灰泥、玄武岩、赤金、木料、盐壳、辉光晶体共 9 套 16×16 程序化像素贴图，全部由代码算出（期间还修掉了一个通道溢出 255 回绕成假蓝色的 bug）。

## 六、没做完 / 已知限制

* **水面是程序化近似**，不是真正的镜面反射——为了让 8.5 万个方块也能实时跑，没有再做一次全场景反射渲染。
* **建筑外部是空心壳**：为了性能，鼓座与基座只生成可见的表皮（内部掏空），从下方贴近看能看到局部空腔。
* **盐滩远景是一张无贴图的大平面**，靠世界坐标噪声打散，和近处体素盐壳之间的接缝在雾里基本看不出，但没有做到完全无缝。
* 本机环境是软件渲染（SwiftShader），因此截图里的帧率读数很低；在有独立显卡的机器上这个场景（约 12 个材质批次、十余万三角形、一次阴影贴图）应当轻松跑满。
* 三个版本的方块数量我按最终构建取的整数（`window.__bench.blocks` 为准）。
