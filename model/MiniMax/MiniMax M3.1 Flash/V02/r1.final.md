# AURORA — 一辆完全由代码生成的自行车

> 所有几何、纹理、光照、动画、声音都在运行时现场生成。
> 没有任何外部图片 / 模型 / 音频 / 字体文件；唯一的第三方文件是本地化的 three.js r155（`bicycle/vendor/three.min.js`）。

---

## 一、怎么看

**双击 `bicycle/index.html`**（Chrome / Edge），不需要起服务器、不需要联网。

| 操作 | 效果 |
| --- | --- |
| 鼠标拖动 | 转动镜头（方位角 / 仰角） |
| 滚轮 | 缩放（带阻尼） |
| 数字键 `1`–`6` | 切到六个预设机位 |
| 空格 / `RIDE` 按钮 | 起步 / 停下 |
| 左下角滑杆 | 车速 0 – 12 m/s（实时显示 km/h） |
| `SOUND` 按钮 | 开/关现场合成的骑行声 |

## 二、交付内容

```
bicycle/
  index.html            入口页面（UI + 加载层 + 契约）
  js/lib.js             数学/几何工具、程序化 canvas 纹理、材质库、齿形生成器
  js/bike.js            车架、前叉、轮组、传动、座垫、把组、刹车
  js/stage.js           PMREM 环境、灯光、展台、平面反射、后期链
  js/sound.js           WebAudio 合成音（轮胎轰鸣 + 链条棘轮）
  js/main.js            相机机位、主循环、window.__bench 契约、界面
  vendor/three.min.js   three.js r155 UMD（本地化，保证 file:// 双击可用）
```

工作目录里另外留了两个自检工具：`verify.js`（几何 / 传动 / 零件树核对）、`capture.ps1`（无头 Chrome 批量截图）。

### 契约实现

```js
window.__bench = {
  views: ['side','three_quarter','top','closeup_drivetrain','closeup_front','closeup_wheel'],
  setView(id), listParts(), setSpeed(v), getState()
};
window.__scene;  window.__renderer;  window.__bike;   // 另有 __bike 便于调试
```

`getState()` 返回 `{ speed, wheelAngle, crankAngle, wheelRadius, chainringTeeth, cogTeeth }`，
角度为弧度、只增不取模；`wheelRadius = 0.35 m`；`chainringTeeth = 50`；`cogTeeth = 17`。
`setView` 用 0.9 s 的 cubic ease-in-out 同时插值方位角 / 仰角 / 距离 / 焦点 / 景深，方位角走最短路径。

**无头自检结果**（`?selftest=1`，headless Chrome + SwiftShader）：

```
wheelRate 5.7143  (exp 5.7143)   crankRate 1.9429  (exp 1.9429)
ratioOK true   speed 2   R 0.35   teeth 50/17   parts 13   views 6   monotone true
```

即：车轮与曲柄的角速度比严格等于 50/17，角度随时间单调递增，零件树与视图数量符合约定。

## 三、机器本身（懂车的人请看这里）

**整车几何**（脚本核对值）

| 项目 | 数值 |
| --- | --- |
| 轴距 | 1004.4 mm |
| 后下叉 | 411.8 mm |
| 五通高 | 272.5 mm |
| 头管角 | 72°（管长 200 mm） |
| 坐管角 | 73.5° |
| 轮胎 | 700 × 38C，622 BSD 圈径，胎外径 Ø700 mm |

**传动系**

- 牙盘 50/34T（2×），11 速飞轮 11–30T，当前啮合 **17T**，速比 **2.9412 : 1**。
- 30 km/h 对应踏频 77.3 rpm；8 m/s 时车轮 218.3 rpm、曲柄 74.2 rpm。

**链条是算出来的，不是画出来的**

链条按"四轮盘多边形带（polygonal belt）"建模：

- 1/2″ 链距（12.7 mm），**108 节**（偶数，和真车一样成对），总长 1.3704 m，
  平均节长 12.689 mm vs 标准 12.700 mm（误差 0.09%）。
- 每个链节是一个带滚子与销轴的实体：链板 6.6 mm 高、滚子 Ø7.4 mm、外宽 5.6 mm（11/12 速窄链规格）。
- 四个轮盘（牙盘 / 张力轮 / 导轮 / 飞轮）的**齿槽相位由链条带求解器反推**，
  所以滚子是真的坐在齿谷里，而不是"看起来差不多"。
- 曲柄转一圈，链条前进 50 × 12.7 mm；飞轮与车轮严格转 50/17 圈（数学精确，不是近似）。
- 链条节数由"导轮 / 张力轮位置"网格搜索 + 局部细化反解，保证节距取整误差最小且节数为偶数。

**轮组与制动**

- 32 根三交叉编法辐条（实体、不是贴图）、双法兰花鼓、辐条铜头、黄铜气嘴。
- 碟片带 12 个减重孔与 6 爪花键；**卡钳跨骑在碟片上**（距花鼓 70 mm，落在 62–80 mm 的制动带上），
  两只卡钳分别夹在前叉腿与后上叉上（左侧，符合碟刹布局）。
- 脚踏平台从曲柄外侧悬挂，随曲柄转动而自身保持水平。

**材质**：漆面（金属颗粒 + 清漆）、皮革、胎面、胎侧、拉丝金属等纹理全部用 canvas 程序化绘制；
环境光照用程序化 studio 场景烘成 PMREM，没有一张外部贴图。

## 四、画面

- 渲染链：HalfFloat 场景 RT + MSAA(4) + 深度纹理 → **自写后期**：三级 bloom、基于深度纹理的景深、
  ACES 色调映射 + 胶片调色、暗角、胶片颗粒、径向色散。
- 展台顶面叠加一层镜像相机渲染的平面反射（强度 0.2），底材压暗粗糙，避免过曝白块。
- 空气里有缓慢飘动的尘埃粒子；展台边缘有一道暖色轮廓光。
- 配色：深青漆面 + 黄铜牙盘 + 棕褐胎壁 + 冷钢，冷暖对撞的"暮光工作室"。

**转场**：六个机位之间的切换不是硬切，而是 0.9 s 内同时插值机位与景深参数（缓入缓出），
因此侧视 → 俯视 → 特写是一条连续的运镜线；拖动时用指数阻尼跟随，松手自然停住。

## 五、性能

- 设备像素比上限 1.5；内部渲染倍率按帧耗时在 0.5–1.0 之间自适应。
- 反射 RT 640×320 隔帧刷新；阴影贴图 1024；后期链做了降级。
- 说明：这台开发机只有软件渲染（SwiftShader），实测约 5–6 fps；真实 GPU 上会快得多，
  但我无法在本机验证 GPU 表现。

---

## 六、没有做的部分（如实说明）

- 没有刚体物理：轮胎不变形，链条是刚性多边形带，没有真实的链条垂度与张力变化。
- 没有变速机构的逐级手感：档位是"设定"，不是棘轮一格一格的过渡。
- 胎面只有纹理，没有真实的胎块几何。
- 声音是合成的风声与链条声，不是实录采样；浏览器策略要求先有一次用户点击才会发声。
- 界面是英文的（题目与评审语言是中文，但作品本身用了极简英文排版）。

   曲柄转一圈链条正好前进 50 节，飞轮跟着转 2.94 圈，牙盘/飞轮的齿相位是对得上的。
2. **`top` 与 `side`** —— 整体比例与配色：钢架 all-road 的姿态，加上黄铜牙盘和棕胎壁的暖色点缀。
3. **拖动镜头时** —— 景深会跟着焦点变化，展台上有车的倒影，尘埃在光束里飘。
