# 外部渗透测试摘要（节选）

公司计划把 TeamNotes 开放给合作方使用，请在上线前完成安全加固。渗透测试人员只给出了摘要和 4 条已确认的发现，**完整的清单需要你自己审计**——他们表示“这只是在两天里发现的几个，实际问题不止这些”。

## 已确认的发现

1. **搜索接口异常响应**：在搜索框输入单引号会得到服务端错误，输入特定字符串时能看到其他人的笔记。
2. **越权读取**：登录后把笔记 ID 改成别人的，能读到别人的笔记内容。
3. **口令存储**：拿到数据库文件的人可以直接用常见彩虹表还原多数用户的密码。
4. **页面脚本执行**：笔记标题里写 `<script>`，通过“渲染”页面打开时会执行。

## 其它要求

- 修复不能破坏现有功能：接口、状态码、错误格式、数据文件格式的兼容（已有用户的账号仍应能登录，或给出迁移方案）。
- 不要引入运行时第三方依赖。
- 每一类问题写一条能证明“攻击不再成功”的测试。
