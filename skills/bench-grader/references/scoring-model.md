# 评分模型

## 1. 三类检查
| 类型 | 谁来评 | 说明 |
|---|---|---|
| 门槛（gates） | 自动 | 能运行、交付物存在、最终汇报与实际一致。任一不过：该次运行全部维度分与总分记 0，进入失败归因。门槛指标为 N/A 时跳过该门槛。 |
| 自动项（method: auto） | 探针 | 指标 → 规则 → 0–1 分。 |
| Agent 项（method: agent） | 执行本 skill 的 agent | 阅读代码/文档，按 4 级锚点打 0–3 分并写证据；用户可覆盖。 |
| 人工项（method: human） | 用户 | 只保留必须看/听/操作才能判断的项；盲评、横向比较。 |

## 2. 层级与权重
| 层级 | 默认权重 | 作用 |
|---|---|---|
| basic 基础 | 1 | 大多数模型应能做到，防止“完全没做” |
| advanced 进阶 | 2 | 主要区分来源 |
| excellent 卓越 | 3 | 专门拉开头部差距：定格节奏、节拍对齐、级分离精度、未报告缺陷、矛盾识别等 |
| clean 扣分项 | 1 | 满分表示“干净”：零报错、无占位代码、无 PIN 明文等 |

检查项可以用 `weight` 覆盖默认权重（例如 T07 的测试分类按测试数量加权）。

## 3. 换算规则
| 规则 | 参数 | 得分 |
|---|---|---|
| bool | expect（默认 true） | 相等得 1，否则 0 |
| eq | value | 等于目标值得 1 |
| ratio | — | 值本身（截断到 0–1） |
| min | min, zero? | ≥ min 得 1；给了 zero 时在 zero→min 间线性，否则 0 |
| max | max, zero? | ≤ max 得 1；给了 zero 时在 max→zero 间线性下降 |
| linear | bad, good, log? | bad→good 线性映射到 0→1，可对数刻度；good < bad 表示越小越好 |
| band | lo, hi, tol | 区间内 1，偏离 tol 记 0 |
| 锚点 | 0–3 | 除以 3 |

`value_expr` 可用多个指标组合出一个值，例如 `"v['video.width'] == 1920 and v['video.height'] == 1080"`。

## 4. 状态
- **scored**：正常评分。
- **missing**：被测产出没有提供该指标（接口未实现、文件不存在、JS 抛错）→ 0 分，计入分母。
- **na**：评测环境原因无法检查（没有 ffmpeg、npm 不通、未配置 axe）→ 不计入分母；单次运行 N/A 权重占比超过 `low_confidence_na_ratio`（默认 20%）标记“低可信”。
- **pending**：人工/agent 项未评 → 不计入分母，报告标“评分不完整”。正式发布前必须清零。

## 5. 分数公式
```
单次维度分   = 100 × Σ(w·s) / Σw        只计该维度的 scored + missing 项
单次总分     = 100 × Σ(w·s) / Σw        该次运行全部 scored + missing 项
达标         = 门槛通过 且 单次总分 ≥ pass_threshold（默认 60）
题目维度分   = 同一参赛者同一题（含 A/C 变体）多次运行的均值
参赛者维度分 = Σ(题目对该维度的权重 × 题目维度分) / Σ权重    （rubric 的 dims：主要 1.0，次要 0.5）
质量总分     = Σ(dimensions.yaml 中质量维度权重 × 维度分) / Σ权重
```
参赛者 = “模型 @ harness”。同一模型换 harness 视为不同参赛者。

## 6. 效率维度
- 期望成功成本 = 单次平均费用 ÷ 达标率；达标率为 0 时为 ∞（得 0 分）。
- 期望达标用时 = 单次平均有效用时 ÷ 达标率。
- 用 `benchmark.yaml` 的固定锚点在对数刻度上换算为 0–100（默认成本 0.3→30 美元、用时 5→180 分钟）。锚点固定，新增参赛者不改变已有分数。
- 参赛者的效率分 = 各题效率分平均；另报告“整套期望成本/用时”（各题之和）。
- 默认不合成综合分；如需要，在 `composite` 中开启并写明权重。

## 7. 置信区间与并列
- 对每个参赛者，在每道题内部有放回重抽运行（默认 2000 次），重算质量总分，取 2.5%/97.5% 分位。
- 排名：按质量总分降序；与本组首位置信区间重叠的记为并列（名次加“=”）。
- 每题只有 1 次运行时区间会退化，报告中应提醒“运行次数不足”。

## 8. 防天花板设计清单
1. 三层权重，卓越层单项权重高。
2. 能用连续指标就不用通过/不通过（帧率、误差、比例、通过率、延迟）。
3. 隐藏测试覆盖边界、时区、并发、安全，而不只是主流程。
4. 埋入“题面之外”的难点：T08 未报告缺陷 B5、T06 两处需求矛盾、T07 规格空白。
5. 精确目标值：T05 发动机数量、分离时刻；T06 真实意图的 4 小时与今明两天窗口（只有问了才可能命中）。
6. 分层得分表单独报告：基础项普遍满分时，看进阶/卓越层。
7. 题目分析：跑完一轮后替换“天花板”项。
