# The Long Way Home

一只鹈鹕，在一天最后的金色余光里，骑着老式自行车沿海边木板路回家。车篮里是今天的鱼，车灯照着一小段路，远处的灯塔亮着。它戴着一顶旧呢帽、系着一条被风吹起来的红围巾——这是它的通勤，也是它的一天。

## 怎么看

直接双击 **`pelican/index.html`** 即可。不需要启动服务器，不需要联网；Three.js 已随作品放在 `pelican/vendor/three.min.js`。

- **拖动**：转动镜头；**滚轮**：缩放；触屏支持双指缩放。
- 六个取景按钮在页面顶部：side / front / three-quarter / top / the bill / the pedals。
- 底部中央是 **2.5D / 3D** 切换按钮，也可以用键盘 `M`。
- 键盘 `1`–`6` 切换取景，`S` 开关声音。
- 声音默认关闭，点击右上角 sound 之后才会启动（浏览器自动播放策略）。

## 做了什么

同一个瞬间被做了两遍：

- **2.5D**：纯 SVG + JavaScript 的矢量世界。所有道路、车轮、车架、身体和羽毛都由共享的三维相机投影到 SVG 上，再按深度分层上色。有滚动木板、透视栏杆、云层、海面反光、远山灯塔、海鸥、帆船、尘土和会飘走的羽毛。它是一幅会呼吸的插画，不是一张静态图。
- **3D**：Three.js r157 的完整场景。天空和海面是自写 shader；木纹、羽毛、藤编、皮革等纹理全部由 Canvas 现场生成；有低角度阳光、柔和阴影、程序化云层、灯塔光束、车灯投在木板上的暖光池，以及带 IK 的踩踏腿、链条、围巾飘动。
- 两种模式共享 `world.js` 里的同一套骨架、同一组关节、同一个相机和同一个骑行相位。切换模式不会重播：鹈鹕、曲柄、车轮、围巾和镜头都停在同一个瞬间。
- 3D 暴露 `window.__scene`（THREE.Scene）和 `window.__renderer`（THREE.WebGLRenderer）；两种模式都有 `window.__bench` 约定的六个视角、`setView`、`setMode`、`getMode`，以及包含 49 个部件的 `listParts()`。
- 声音：程序化 WebAudio 海浪、风、链条咔哒声、远处海鸥和一点低频底噪；全部实时合成，没有音频文件。

## 最想让你多看两眼的地方

1. 在 **side** 取景下按一下 **2.5D / 3D**：绘画和雕塑在同一条地平线、同一个骑行相位上互换。这是整个作品的核心。
2. **closeup_head**：鹈鹕的帽子、围巾和喙袋；3D 里的羽毛凹凸纹理与逆光轮廓。
3. **closeup_legs**：脚踏、曲柄、链条、齿盘和真正落在踏板上的蹼足；2.5D 与 3D 的机械关系在这里对得上。
4. **three_quarter**：翅膀搭在车把上的姿态，以及车篮里探出的鱼尾。
5. 打开声音，再回到 **side**：海、风、链条和远处海鸥。

## 自检

作品用 Playwright + headless Chromium 从 `file://` 实际打开并逐项验证过，结果在 `qa/report.md` / `qa/report.json`，截图矩阵在 `qa/shots/`：

- `window.__bench` 接口、六个视角名、两种模式、`setView` 用时、拖动/滚轮、模式切换后的骑行相位连续性全部通过；
- `window.__scene` / `window.__renderer` 类型正确；2.5D 为 676 个 SVG 节点；
- 没有任何外部图片、字体、音频请求，控制台无错误；
- 12 张最终截图（两种模式 × 六个视角）。

可复现：`node qa/run.cjs`，或 `node qa/run.cjs --no-shots`。

## 诚实的限制

- 这是一个风格化作品，不是博物学复原：喙袋、身体和羽毛都做了图形化处理，2.5D 尤其如此。
- 2.5D 的 front / top 取景比 side 更像版画式构图；3D 在软件光栅环境（headless / SwiftShader）里帧率会明显低于真实 GPU，实际 Chrome 硬件加速下应流畅。
- 画面里的所有内容都是代码生成的；唯一的外部代码库是固定版本的 Three.js r157。
- 声音是环境性的、克制的，不是配乐；默认静音。
