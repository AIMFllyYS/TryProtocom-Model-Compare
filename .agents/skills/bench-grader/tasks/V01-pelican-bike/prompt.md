# 鹈鹕骑自行车

## 契约

- 在工作目录下新建文件夹 `pelican/`，入口是 `pelican/index.html`。Chrome 双击就能运行，不需要启动服务；可以拆成多个文件，但都放在这个文件夹里。
- 可以从 CDN 加载你需要的开源库（固定版本号）。但所有画面都要由代码当场生成：几何、纹理、光照、动画、声音都不要引用或携带外部图片、模型、音频、字体文件。
- 鼠标拖动可以转动镜头，滚轮可以缩放。
- 页面加载后把下面这个接口挂在 `window` 上，评测会用它逐个取景拍照：

```js
window.__bench = {
  views: ['side', 'front', 'three_quarter', 'top', 'closeup_head', 'closeup_legs'],
  setView(id) {},      // 把镜头切到这个命名视角（可以做过渡动画，1 秒内完成）。取景由你决定，让主体好看
  setMode(m) {},       // '2.5d' | '3d'。切过去就停在这一帧的骑行状态上，不要从头重播
  getMode() {},        // 返回当前模式
  listParts() {},      // 可选，但鼓励：返回部件树 [{ id, name, parent }]，方便检查你把东西拆得多细
};
```

- 页面必须同时有两种模式，并有一个一眼能看见的切换按钮。评测的人要能来回看这两种画面：
  - **2.5D**：用 SVG 画出来，分层、有纵深，不是一张静态图。
  - **3D**：用 Three.js 画出来，并暴露 `window.__scene`（THREE.Scene）和 `window.__renderer`（THREE.WebGLRenderer）。
  - 两种模式是同一只鹈鹕、同一辆车、同一个骑行瞬间。切换时保持骑行相位和速度，不从头重播。怎么过渡由你决定。
- 两种模式里都要能拖动镜头、滚轮缩放，`setView` 在当前模式里也能用。
- 完成时在工作目录写 `FINAL_MESSAGE.md`，说明做了什么、怎么看、哪里最想让我多看两眼。

## 愿望

我想看到一只鹈鹕骑着一辆自行车。它在哪里、怎么骑、是什么气质，镜头、光线、风格、有没有声音，一切都由你自己分析和决定，可以融入叙事，也可以只是一个瞬间；我不替你指定任何风格。

唯一的底线是结构要成立：脚真的踩在踏板上，翅膀真的搭在车把上，自行车是一辆机械关系正确、真能骑的车。

同时，无论是 JavaScript、WebGL、Three.js 还是什么各种技术都可以，用你最大的努力，我希望：

1. 作品本身视觉是惊艳的、艺术性顶尖的。
2. 内容本身是高级的、有深刻含义的。
3. 转场、画面（或镜头、场景、交互）之间的衔接是自然的：可以一镜到底，或者至少画面和画面之间有主线、不突兀。
4. 从观众的视角感受到的是大师之作，并且震惊这竟然是用代码生成的。
5. 可以不限 token，尽可能炫技。
