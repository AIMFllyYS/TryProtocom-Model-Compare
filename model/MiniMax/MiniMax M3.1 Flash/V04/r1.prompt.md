# Aether-9 重型火箭 3D 交互官网

## 契约

- 在工作目录下新建文件夹 `aether9-site/`，入口是 `aether9-site/index.html`，用本地静态服务打开即可运行。技术栈、框架、构建工具都由你定；可以从 CDN 加载开源库（固定版本号），如果有构建步骤，请保证 `npm ci && npm run build` 能从零复现，并把可直接运行的构建结果放在 `aether9-site/index.html`。
- 画面必须当场生成：几何、贴图、环境光照、字体效果都由代码产生，不引用或携带外部图片、模型、音频、字体文件；除开放 CDN 之外，运行时不发起其他网络请求。
- 虚构背景，不需要上网调研。官网上出现的事实以下表为准，不得自行编造其他参数：

| 参数 | 数值 |
|---|---|
| 全高 / 直径 | 118 m / 9 m |
| 一级 | 可回收助推器，21 台甲烷发动机，带 4 片栅格舵 |
| 二级 | 6 台发动机，含 3 台真空版 |
| 近地轨道运力 | 120 t（完全复用） |
| 一级分离 | T+160 s，高度约 70 km |

- 为了让评测能核对“箭体与参数表一致”，请用下面的命名：一级发动机的 3D 对象名以 `engine-s1-` 开头，二级海平面发动机以 `engine-s2-sl-` 开头，真空发动机以 `engine-s2-vac-` 开头，栅格舵以 `gridfin-` 开头；每台发动机、每片舵对应且只对应一个这样命名的对象（可以是 Group），其子对象不要再使用这些前缀。
- 页面加载后挂出下面的接口（评测用它取景、展开、发射、读遥测）。如果使用 three.js，另外暴露 `window.__scene` 与 `window.__renderer`。

```js
window.__bench = {
  views: ['overview', 'stage1_engines', 'stage2', 'gridfin_closeup', 'launch_pad'],
  setView(id) {},                    // 把主镜头切到一个命名视角；停止自动运镜，方便截图
  listParts() {},                    // 返回部件树 [{ id, name, parent, object3dName }]，object3dName 是它在 __scene 里的对象名
  explodePart(id, on) {},            // 把单个部件（含其子部件）从整体里拉开 / 复位
  setExploded(on) {},                // 一键分级爆炸：一级与二级沿轴线分开
  listHotspots() {}, openHotspot(id) {},  // 部件热点与说明
  launch() {}, setTimeScale(k) {},   // 发射演示；k 倍速，评测会用 20 倍
  getTelemetry() {},                 // { t, altitudeKm, velocityMs, stage }，stage 为 1 或 2（分离后为 2）
  scrollToSection(id) {},            // id ∈ 'hero' | 'specs' | 'launch' | 'reuse' | 'cta'
};
```

- 页面至少有首屏、参数、发射演示、复用流程、行动号召这几个区块，桌面（1920×1080）和手机（390×844）都要布局合理；控制台不要报错。
- 完成时在工作目录写 `FINAL_MESSAGE.md`：交付了什么、有哪些你自己加的交互，只写真实存在的内容。

## 愿望

我想要一个像真正的航天公司发布会那样的官网，核心是一枚能被“拆开看”的火箭：从整箭到级、到系统、到部件都能单独看、单独拆，点中任意一个部件，它能被讲清楚是什么、为什么这样设计，而不是只会整体转动的模型。发射、分离、回收的过程要让人看完就明白“可复用”为什么重要。除此之外，请再设计至少一个你认为新颖的交互，并用一句话说明它帮用户理解了什么。

页面的整体风格、视觉语言、节奏、叙事方式、做多细、用什么技术，都由你自己分析和决定，可以结合叙事，我不指定任何风格。

同时，无论是 JavaScript、WebGL、Three.js 还是什么各种技术都可以，用你最大的努力，我希望：

1. 作品本身视觉是惊艳的、艺术性顶尖的。
2. 内容本身是高级的、有深刻含义的。
3. 转场、画面（或镜头、场景、交互）之间的衔接是自然的：可以一镜到底，或者至少画面和画面之间有主线、不突兀。
4. 从观众的视角感受到的是大师之作，并且震惊这竟然是用代码生成的。
5. 可以不限 token，尽可能炫技。
