# 交付说明 · The Last Cathedral / 余烬大教堂

## 一分钟看懂

- **入口**：`mc-build/index.html`。单文件、离线可开（three.js 已内联），Chrome 双击直接运行，无需服务器、无需联网。
- **打开后**：先出现加载幕（约 2–3 秒，实时构建 32 万方块、烘焙光照、合并网格），随后自动播放约 40 秒**一镜到底**的开场：从云海之上掠过浮空岛，穿过正门进入中殿，最后停在祭坛前。
- **操作**：拖拽环绕 / 滚轮推拉 / 右键（或 Shift+拖拽）平移；`1–5` 切五个命名视角，`R` 重播开场，`H` 隐藏界面；右上角五个视角按钮可点；右下角可打开程序生成的氛围声（默认关闭）。
- **自检**：`qa/REPORT.md` 与 `qa/shots-final3/` 是最新一次完整截图与报告；`qa/shots-evalpattern/` 是“评测器模式”验证（ready → setView → 截图）的通过证据。

## 我建了什么

**世界观**：一块漂浮在云海之上的世界残片「Aur」，一所建给“最后一道光”的哥特式大教堂。太阳正在沉入云海，天空里悬着一颗带环行星；教堂把最后一点余烬保存在祭坛上方的黄铜浑天仪里。它既是一座建筑，也是一座灯塔——为那些不愿让光熄灭的人而建。

**规模**：约 **327,000 个方块**，全部对齐 1 单位网格，`blockSize = 1`；面剔除后约 **60 万三角形**、约 **145 个绘制批次**（headless Chrome / SwiftShader 下约 60fps）。所有方块、贴图、光照、云、星空、行星、粒子都是代码在运行时生成的，没有引用任何外部图片、模型、音频或字体。

**建筑**：
- 双塔西立面（约 145 格高），带钟面、百叶钟楼、尖顶、金色十字与风向标式小尖饰；带深色石环的圆形玫瑰窗，12 瓣彩色玻璃与石质窗棂。
- 中殿 / 侧廊 / 耳堂 / 半圆后殿；尖拱连拱、束柱、肋拱、飞扶壁、铜绿坡屋顶与金色屋脊、老虎窗、十字脊塔与尖塔。
- 内部：红毯、长椅、吊灯、烛台、壁灯、挂旗、圣徒与天使体素雕像、唱诗席台阶、金色祭坛与可发光的“余烬”浑天仪；地面有迷宫纹样。
- 环境：浮空岛地形与岩层、瀑布式云海边缘、松林与枯树、墓园、残破柱廊、仪式大道、镜面水池、罗盘迷宫、方尖碑、火盆、路灯、鸟群、飘浮的余烬与尘埃。

**光**：自己写的体素光照洪水填充——从天空向下投射日照，再让彩色玻璃与灯笼/余烬作为彩色点光源在空气里逐格衰减，最后把 RGB 光照、AO、朝向和每块色差烘进顶点属性。所以中殿里的彩色光斑、玫瑰窗投下的光柱、烛光下的石柱明暗，都是从方块世界里真实算出来的，不是贴图假光。

## 接口（评测约定）

```js
window.__scene     // THREE.Scene，整个世界
window.__renderer  // THREE.WebGLRenderer
window.__bench = {
  views: ['exterior_far', 'exterior_near', 'aerial', 'interior', 'detail'],
  setView(id),     // 立即切到命名视角并停止自动运镜；干净画面（无标题/加载幕残留）
  blockSize: 1,
  ready: true,
}
```

`window.__scene.userData` 还提供了 `blocks`（Float32Array，每 4 个数一组 `x,y,z,blockType`）、`blockCount`、`blockSize`、`bounds`、`getBlock(x,y,z)` 与统计信息。另暴露 `window.__camera`、`window.__rig`、`window.__blocks`、`window.__light` 方便检查。

## 技术与性能要点

- 逐面剔除的体素分块网格（chunk 32），自定义 ShaderMaterial：图集采样 + 顶点烘焙 RGB 光照 + 自发光；无 per-frame 光照计算。
- 程序化 512² 像素图集（49 种材质，全部 Canvas 绘制），最近邻放大 + mipmap。
- 自定义后处理：HDR 场景 → 亮部提取 → 两次分离高斯 → ACES 色调映射 + 暗角 + 颗粒 + 轻微色偏；超采样抗锯齿。
- 程序化天空（太阳、星空、晨昏渐变）、带环行星、双层 fbm 云海、光束锥、尘埃/余烬/萤火粒子、程序化水面、鸟群。
- 开场用 Catmull-Rom 连续路径 + FOV 变化，一镜完成；任何手动操作会平滑接管。`setView` 会立即冻结并清掉所有覆盖层。

## 已知取舍

- 相机是可环绕/推拉的“电影机”，**没有碰撞与步行模式**；内部空间可以进入、可以环绕看，但不会第一人称行走。
- 开场约 40 秒；评测直接调用 `setView` 会跳过它并立即给干净画面。
- 视觉上做了电影化处理：可见落日方向与照射方向并不完全物理一致（一个负责天空，一个负责打亮正立面）。
- 声音是 WebAudio 程序生成的持续低音/风声/钟声，默认关闭，需要点一下右下角。
- 体素造型受 1 格尺度限制，玫瑰窗与雕像在极近距离能看到台阶状边缘——这是有意保留的“方块感”。
