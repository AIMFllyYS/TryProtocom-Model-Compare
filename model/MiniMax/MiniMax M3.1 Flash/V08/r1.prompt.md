# Aether-9 发布宣传片（HyperFrames 端到端制作）

## 契约

- 输入：事实表 `assets/aether9-facts.md`（虚构火箭，所有内容以事实表为准，不需要上网调研，不得编造其他参数）；素材包 `assets/bgm-a.wav`、`assets/bgm-b.wav`（二选一）和 `assets/sfx/` 下的音效。画面素材只能来自这些素材和你用代码生成的图形。
- 配音：使用评测环境预装的 TTS 命令 `python "D:\projects\Model-Compare\My-BenchMark\workbench\scripts\bench_tts.py" --voice zh-CN-YunxiNeural`（例如 `tts --voice zh-female --text "…" --out out.wav`）。
- 工具：已安装 HyperFrames 及其官方 skills，请用它完成制作与渲染。
- 成片 `final.mp4`：1920×1080，30fps，H.264 视频 + AAC 音频。
- 字幕：烧录进画面，中英双语，每句只占一行，过长拆成多条，不要自动换行；同时导出 `subtitles.srt`。
- 混音：整体响度 −16 到 −14 LUFS，真峰值不超过 −1 dBTP；旁白出现时 BGM 自动压低。
- 在工作目录下新建文件夹 `aether9-promo/`，放入 `final.mp4`、`subtitles.srt`、`script.md`（你撰写的旁白脚本）和 HyperFrames 项目源码。
- 完成时写 `FINAL_MESSAGE.md`：交付了什么，只列出真实存在的文件。

## 愿望

我想要一支让人想看完并转发的 Aether-9 火箭发布宣传片。推荐时长约 20 秒，但多一些、少一些都没有问题，时长由你根据内容决定。

信息从事实表里取舍，讲清“这枚火箭为什么不一样”；视觉风格、叙事方式（可以结合叙事，也可以不用）、怎么剪、怎么设计、用几个场景，都由你自己分析和决定，我不指定任何风格。

同时，无论是 JavaScript、WebGL、Three.js 还是什么各种技术都可以，用你最大的努力，我希望：

1. 作品本身视觉是惊艳的、艺术性顶尖的。
2. 内容本身是高级的、有深刻含义的。
3. 转场、画面（或镜头、场景、交互）之间的衔接是自然的：可以一镜到底，或者至少画面和画面之间有主线、不突兀。
4. 从观众的视角感受到的是大师之作，并且震惊这竟然是用代码生成的。
5. 可以不限 token，尽可能炫技。
