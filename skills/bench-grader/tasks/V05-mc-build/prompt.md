# 方块世界里的宏大建筑

## 契约

- 在工作目录下新建文件夹 `mc-build/`，入口是 `mc-build/index.html`，能在 Chrome 里直接打开、实时渲染。技术栈自选；可以从 CDN 加载开源库（固定版本号）。
- 所有方块、贴图、光照都由代码当场生成（像素贴图可以用 Canvas 程序化绘制），不引用或携带外部图片、模型、音频、字体文件。贴图与方块造型是原创的“Minecraft 风格”设计，不复制官方素材。
- 世界必须是真正的体素：建筑由一格一格的等大立方体方块搭成，方块对齐到同一个网格。评测会读取 `window.__scene` 里的方块来核对，所以请使用 three.js，并把整个世界放进 `window.__scene`（可以用 InstancedMesh、合并网格或分块网格，随你）。另外暴露 `window.__renderer`。
- 页面加载后挂出下面的接口：

```js
window.__bench = {
  views: ['exterior_far', 'exterior_near', 'aerial', 'interior', 'detail'],
  setView(id) {},       // 把相机切到一个命名视角并暂停自动运镜，供截图使用
  blockSize: 1,         // 每个方块的世界尺寸（单位长度）
};
```

- 页面要有可以自己操作的镜头（拖拽环绕 / 漫游均可），打开后不需要点任何东西就有画面；控制台不要报错，重度场景下也要尽量保持可交互的帧率。
- 完成时在工作目录写 `FINAL_MESSAGE.md`：你建了什么、有哪些操作方式、有哪些你自己加的细节，只写真实存在的内容。

## 愿望

请在方块世界里建一座你能想象到的、最宏大的建筑（种类、风格、文化背景都由你选），有真正可以走进去的内部空间。

怎么设计、做多大、配色与氛围、周围的环境、是否带叙事、先做什么后做什么，都由你自己分析和决定，我不指定任何风格。

同时，无论是 JavaScript、WebGL、Three.js 还是什么各种技术都可以，用你最大的努力，我希望：

1. 作品本身视觉是惊艳的、艺术性顶尖的。
2. 内容本身是高级的、有深刻含义的。
3. 转场、画面（或镜头、场景、交互）之间的衔接是自然的：可以一镜到底，或者至少画面和画面之间有主线、不突兀。
4. 从观众的视角感受到的是大师之作，并且震惊这竟然是用代码生成的。
5. 可以不限 token，尽可能炫技。
