# HAVN LESEHAL — 逼真的建筑（实时渲染）

> 一座建在渔港尽头的 24 小时公共阅览室。整幅画面——几何、材质、贴图、天空、海水、环境光、后期——全部由代码当场生成，没有任何外部图片 / HDR / 模型 / 字体文件。

---

## 1. 我建了什么

**《HAVN LESEHAL》（港湾·阅览室）**

一座单坡铜顶的木构阅览室，架在挪威式渔港最外端的石制港头平台上，正面朝陆，落地玻璃对着海。码头从画面下方一直伸到建筑脚下，铺着被海风和盐蚀旧了的松木栈板，尽头泊着一条小渔船，远处有礁石灯塔、对岸的村屋与教堂尖顶。

**叙事**：这个镇子把船都卖了，只把灯留着。铜屋顶下是全天不熄灯的公共阅览室——一座"没有人要求它存在，但它一直开着"的建筑。招牌上写着 `HAVN LESEHAL` / `THE READING ROOM · OPEN 24 HOURS`，侧挂灯箱是挪威语 `ÅPENT 24 TIMER`。黄昏那一档（21:40）就是这盏灯亮起来的时候。

**我做了两套完整的光照状态**，不是滤镜：

## 2. 怎么运行

用 Chrome 直接双击打开：

```
photoreal-building/index.html
```

`file://` 协议下可用，不需要起服务器。

**唯一的外部依赖**是从 jsdelivr 拉取的 three.js **0.169.0**（固定版本，用 import map 引入）：

```html
<script type="importmap">
{ "imports": {
    "three": "https://cdn.jsdelivr.net/npm/three@0.169.0/build/three.module.js",
    "three/addons/": "https://cdn.jsdelivr.net/npm/three@0.169.0/examples/jsm/" } }
</script>
```

> 说明：Chrome 禁止 `file://` 页面加载 `type="module"` 的外部脚本，也禁止跨文件的相对 import，所以最终交付物是**一个自包含的 `index.html`**，里面是一整块 inline module。源码仍然按模块拆分放在 `src/`，由 `build.js` 打包内联——这样既能维护，交付时又只有一个文件。首次打开需要联网取 three.js；除此之外没有第二个网络请求。

## 3. 渲染手段

### 程序化贴图（`src/core.js`）
自带可平铺的 **Perlin 梯度噪声 + fBm**（不是值噪声——值噪声会出现方格晶格，用作高度图时整片墙会读成"砖墙"）。高度图再经 Sobel 求得法线图，并反推 AO 图。

合成的材质组：`concrete`（模板木纹清水混凝土，带对拉螺栓孔与雨渍）、`timber`（雪松）、`plankSet`（栈板，带节疤、藻绿、潮痕）、`copper`（铜）、`stone`（花岗岩）、`oak`（室内橡木）、`ceiling`（浅色上蜡顶板）、以及径向光晕贴图。

**铜屋顶是这轮返工里最费劲的地方**，值得单独说：它一开始读起来像"红瓦屋顶"。原因有三处，都已修掉——
1. 高度通道里混进了竖向条纹场，于是整块铜皮被雕出了密集的竖向棱线，和横向的立边缝叠在一起，就成了瓦片格；现在高度只保留大尺度铜绿晕，铜皮是平的。
2. 粗糙度贴图是高频噪声，在斜射阳光下把金属打成一片"镜面噪点"；现在粗糙度是低频的。
3. 铜皮没有**金属度贴图**。真实的铜绿是介电质氧化物，不是金属；我加了一张 metalness map，让裸铜保持 metalness 1.0、铜绿降到 0.15，铜才真的像铜。

### 天空与环境光（`src/sky.js`）
自写的解析式大气散射天空 shader（天顶/地平/地面/霾四色 + 太阳盘 + FBM 云层 + 夜间星点），渲染进 CubeRenderTarget，再用 `PMREMGenerator` 卷积成 IBL 环境贴图，直接喂给 `scene.environment`。天空随光照预设实时重算。

### 海面（`src/ocean.js`）
4 组 Gerstner 波做顶点位移，片元里算菲涅尔、深水/散射色、太阳耀斑与泡沫；另有一张**半分辨率平面反射**（镜像相机 + 裁剪平面）实时反射建筑与天空。泡沫带跟着浪脊走。

### 后期管线（`src/post.js`）
没有用 EffectComposer，整条 HDR 管线是自己写的：
`场景(HDR, toneMapped=false) → 景深(深度纹理) → 5 级泛光 → 径向体积光 → 合成(AgX 色调映射 + 对比/饱和 + FXAA + 胶片颗粒 + 色差 + 暗角)`

要点：**色调映射只做一次**，放在合成 pass 里，场景里所有材质 `toneMapped = false`，避免二次映射把高光洗白。阴影是 4096² PCFSoft，`shadowMap.autoUpdate = false`（只在换视角时重算）。

### 室内
整间房是实体建模的，不是贴图：橡木地板、顶棚木条、**1816 本独立的书**（InstancedMesh，每本有独立颜色）、6 张阅览桌 + 1 张长 communal table、32 把椅子、8 盏吊灯、书架、吧台、长凳。玻璃是自定义 shader：菲涅尔控制的反射 + 夜间发光。

### 场景统计（运行时实测）
239 个普通 Mesh + 17 组 InstancedMesh（书 1816、立边缝 34、椅子 32、栈板 58、护栏 24、桩 30 …）、163 个 geometry、46 张贴图、33 个着色器程序、13 盏灯。`listParts()` 返回 **47 个部件**，组成一棵 `Pavilion / Interior / Site / Scene` 的树。

## 4. API 与交互

```js
window.__bench = {
  views: ['facade', 'street_level', 'aerial', 'detail', 'dusk'],
  setView(id),   // 'dusk' 同时切到黄昏光照
  listParts(),   // 47 个 {id, name, parent}
  currentView, setDusk(on), camera, controls, lighting
}
window.__scene, window.__renderer, window.__camera
```

- **切换视角**：1.25 s 的缓动（相机位置、目标点、FOV、景深焦距/光圈、阴影重算、以及光照预设**同时**插值）。`dusk` 的光照不是瞬切，是和镜头一起走完这 1.25 s，所以画面之间有连续的主线，不突兀。
- **自己操作镜头**：拖拽环绕、滚轮缩放、右键平移（OrbitControls，带阻尼）。
- **键盘 1–5** 切换五个视角。
- 打开即有画面：加载遮罩在第二帧渲染完成后自动淡出，不需要点任何东西。

## 5. 我自己验证过的（Playwright + 真实 Chrome）

写了两套自动化脚本放在 `_qa/`：`shoot.js`（五个视角各截一张 + 帧率 + 控制台错误）、`contract.js`（逐条核对契约）。

**契约核对结果——全部通过：**

```
PASS  __bench.views 为规定的 5 个 id
PASS  setView() / listParts() 可用，listParts() 返回 [{id,name,parent}]（47 项）
PASS  window.__scene / window.__renderer / window.__camera 已暴露
PASS  未点击任何东西时画布已有真实图像（160×90 采样 525 种颜色）
PASS  加载遮罩自动消失
PASS  setView 五个视角稳定时间：81 / 1300 / 1316 / 1317 / 1302 ms   ← 全部 < 2000 ms
PASS  'dusk' 同时改变太阳强度 (4.7 → 2.4)、太阳高度、曝光与全部光照预设
PASS  拖拽可以环绕（位移 23.2）
PASS  滚轮可以缩放（19.43 → 17.40）
PASS  控制台错误 0
```

**性能与加载**：1600×900 下 rAF 稳定 60 帧/秒（QA 机用的是 Chrome 的 SwiftShader **软件光栅**，真实 GPU 机器只会更宽裕）。全部贴图合成约 **0.7 s**，页面 `load` 事件约 **1.4 s**。

> 顺带修掉的一个真问题：最初首屏要 **15 s**。原因是水面法线贴图那 256² 的循环里，**每个像素都在重新构造一个 fBm 噪声发生器**（每次都要生成 4096 个梯度向量），光这一处就吃掉了 14 s。把发生器提到循环外、并把噪声函数改成无闭包无取模的扁平写法之后，首屏降到 1.4 s。

控制台只有一条来自 three.js 内部的三色图警告（`X3595: gradient instruction used in a loop`），不影响画面。

## 7. 已知不足 / 还没做的

说清楚比藏着好：

- **需要联网**。除 three.js 外零外部资源，但 three.js 本身走 CDN；完全离线打不开。
- **没有人物**。建筑尺度是靠门、椅子、栏杆、灯柱暗示的，没有放人——放人要么露馅，要么变成一个低模穿帮。
- **玻璃不做真实折射**，只有环境反射 + 菲涅尔 + 夜间透光。厚玻璃的色散和边缘暗化没有做。
- **只有轨道相机**，没有第一人称行走。穿到建筑内部从人眼高度看，和从外面看是两种质感，我选了更能出效果的那个。
- **阴影贴图固定 4096²**、只 PCFSoft，够用但不是接触硬阴影级别的精度；阴天没有软阴影过渡。
- **水面是单层 Gerstner**，没有次级波/毛细波细节，远看会略显平。
- `_qa/` 里还留着一批调试期的截图和一次性诊断脚本。我尝试清理，但本机的删除策略不允许（目标路径不在命令工具自身的工作区内），所以保留了原样——不影响交付物。
