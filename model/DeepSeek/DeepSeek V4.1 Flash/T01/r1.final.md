## 建模与物理实现思路（约 200 字）

2.5D 用内联 SVG 分层（天空 / 远山 / 中景 / 路面 / 主体，视差滚动 + 渐变 + 接地阴影），鸟与车拆成 40 余个独立元素，JS 每帧写 `transform` 与 `path`。3D 用 Three.js 程序化建同尺度形体：椭球躯干、`TubeGeometry` 的 S 形颈、圆柱摆位成腿与车架，`CanvasTexture` 画路面，平行光投射阴影 + 半球补光。两模式共用物理核：`ω·R = v` 累加轮转角，曲柄角 = 轮角 × 16/48，踏板反向补偿曲柄转角以保持水平，腿为两段式 IK（膝向前、踝向后凸），脚锁踏板中心；切换模式只换渲染器，不重置相位。

## 实现要点

**物理与传动（两种模式共用同一求解器，故数值完全一致）**
- 无打滑：`state.wheelAngle += speed*dt / R`，R = 0.34 m（700×35c）；轴距 1.06 m、五通高 0.28 m、座垫高 0.70 m。
- 传动比：`crankAngle = wheelAngle × cogTeeth/chainringTeeth = ×16/48`，齿数在 `PHYS` 中为常量并显示在参数面板。
- 踏板平台：2.5D 用 `nearFootG/farFootG` 的世界倾角、3D 用 `pedal.rotation.z = cA - armPhase - wob` 反向抵消曲柄旋转，实测 |倾角| ≤ 0.019 rad（≈1.1°）。脚掌接触点即踏板中心，`footToPedal = 0`。
- 腿部：股骨 0.21 m + 胫跗骨 0.37 m + 跗跖骨 0.15 m，踝（跗间）关节内角 128°；用两段式等效连杆（股骨 + 胫跗骨/跗跖骨合成 0.477 m）做余弦定理 IK，髋固定在座垫上方 0.0885 m，膝顺时针前摆、踝沿法向取「更靠后」的一侧，形成鸟类标志性的向后折角；趾骨与踏板中心重合。

**生物准确性**：物种标注为美洲白鹈鹕 *Pelecanus erythrorhynchos*（白羽 + 黑色初级飞羽、橙黄喙与喉囊、浅黄虹膜、橙色裸足）；长喙带尖端钩与繁殖期上喙角突，喉囊随踏频摆动；足为全蹼足（四趾全部向前 + 趾间满蹼，2.5D 由参数化扇形路径生成，3D 由 `THREE.Shape` 挤出）；颈为 S 形 `TubeGeometry`；翅分覆羽 / 次级飞羽 / 初级飞羽三层，翼尖扶车把。

**音效**：Web Audio 实时合成——链条飞轮咔哒（每踏频圈 8 次啮合，频率随踏频）、风噪（lowpass）+ 胎噪（bandpass）（音量/频率随速度平方）、偶发低频鹈鹕鸣叫（页面已注明成年鹈鹕几乎不发声、此处为艺术化处理）；首次点击页面才创建并启动，控制条可静音，速度为 0 时全部静音。

**界面 / 性能**：模式切换按钮（交叉淡入 0.38 s < 1 s，两模式共享相位）、速度滑块 0–9 m/s、音效开关、参数与物种面板；角落 FPS 计数；SVG 用 `preserveAspectRatio="xMidYMid slice"`、3D 画布随容器重设尺寸，缩放不变形；背景层用取模平移实现无限循环滚动。

## 验证结果（Chromium file:// 实测）

- 控制台：**0 error / 0 warning**（无失败请求、无 uncaught 异常）。
- `wheelAngle` 单调累加不取模；切换模式前后相位连续（`89.36 → 89.65`，未重播）。
- `setSpeed(0)` 后 0.9 s 内 `wheelAngle / crankAngle` 增量恒为 0（全部运动部件静止）。
- `crankAngle / wheelAngle = 0.3333333333`，与 `16/48` 精确一致。
- `pedalAngles ≈ ±0.019 rad`、`footToPedal = [0, 0] m`、`hipToSaddle = 0.08855 m`、`species = "Pelecanus erythrorhynchos"`。
- 切到 3D 后 `window.__scene`、`window.__renderer` 均存在；0 报错。
