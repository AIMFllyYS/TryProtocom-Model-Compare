# 任务：自习室座位预约网页

> 本题以“有人值守”方式运行：模型可以提问，评测者只按《意图表》（hidden/intent.md）作答，意图表没有覆盖的问题一律回答“你来决定”。模型不提问、直接写明假设也允许。以下为发给模型的原文（刻意保留口语化和模糊之处，不要改写）。

---

帮我做个自习室座位预约的网页。我们自习室 20 个座位（A01–A20），前 8 个有插座，A20 坏了在修。同学们主要用手机订。

要求：
- 能看到哪些座位什么时候空着，点一下就能订
- 别让一个人霸占太久
- 订了不来的人得有点惩罚
- 可以提前一周订，方便大家安排
- 不用登录，越简单越好
- 但是要能看到我自己订了什么，别人也不能帮我取消
- 为了公平，只开放明天的座位

先做个纯前端版本，数据存浏览器里就行，后端之后再接。

交付要求：
- 新建文件夹 `studyspot-web/`，主文件 `index.html`（单文件，JS/CSS 内联；如需库，只能从 cdnjs 加载并固定版本）。
- 附 `ASSUMPTIONS.md`：写明你对需求的理解、做了哪些假设、哪些地方你认为需要和我确认。
- 页面需暴露测试接口 `window.__bench`（仅供自动化测试，界面操作必须调用同一套业务逻辑）：
  - `reset()`：清空所有数据
  - `setNow(iso: string)`：设置“当前时间”（例如 `2026-10-08T09:30:00+08:00`）
  - `actAs(studentId: string)`：以某个身份操作（跳过你设计的身份验证步骤）
  - `book(seatId, date, startHour, endHour)` → `{ ok: boolean, reason?: string }`
  - `cancel(bookingId)` → `{ ok: boolean, reason?: string }`
  - `myBookings()` → `[{ id, seatId, date, startHour, endHour, status }]`
- 最后用不超过 150 字说明交付了什么。
