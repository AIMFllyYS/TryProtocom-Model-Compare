# 逼真的建筑（实时渲染）

## 契约

- 在工作目录下新建文件夹 `photoreal-building/`，入口是 `photoreal-building/index.html`，能在 Chrome 里直接打开，实时渲染（不是预渲染的图片或视频）。技术栈自选；可以从 CDN 加载开源库（固定版本号）。
- 所有几何、材质、贴图、环境光都由代码当场生成（程序化纹理、噪声、Canvas 绘制、着色器都可以），不引用或携带外部图片、HDR、模型、音频、字体文件。
- 如果使用 three.js，请暴露 `window.__scene` 与 `window.__renderer`。
- 页面加载后挂出下面的接口，评测用它逐个视角取景：

```js
window.__bench = {
  views: ['facade', 'street_level', 'aerial', 'detail', 'dusk'],
  setView(id) {},    // 相机切到命名视角；'dusk' 同时切到黄昏光照。切换后画面应在 2 秒内稳定
  listParts() {},    // 可选：返回部件树 [{ id, name, parent }]
};
```

- 页面要有可以自己操作的镜头（拖拽环绕 / 缩放）；打开后不需要点任何东西就有画面；控制台不要报错。
- 完成时在工作目录写 `FINAL_MESSAGE.md`：你建了什么、用了哪些渲染手段、有哪些你自己加的细节与交互，只写真实存在的内容。

## 愿望

请做出你能做到的、最像照片的一座建筑（现代办公楼、住宅、教堂、博物馆、旧工厂……自选，只要是你能让它“像真的”的）。

我想要的是站在它面前会本能觉得“这是照片吧”的那种：混凝土、玻璃、金属、砖石、木头各有真实的质感，有细微的污渍、水渍、划痕和接缝；玻璃有反射与折射；光线是物理上可信的软阴影、环境光遮蔽、天空光，黄昏时有暖冷色的对比；镜头有曝光、景深、色调映射带来的摄影感。建筑要有真实的设计：比例、窗墙关系、细部节点、设备与标识，不是一个贴了图的盒子。周围的街道、人行道、树木、街具让它落在真实的环境里。

用什么渲染技术、做到什么程度，都由你决定。
