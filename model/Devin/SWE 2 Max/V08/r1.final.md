## 这片子讲什么

一条完整的"往返"叙事：黎明发射台静立 → 点火（tick 倒数 + rumble）→ 升空爬出大气层（HUD 遥测面板全程报 T+/ALT/VEL）→ **第160秒、70km 一二级分离** → 一级翻转、栅格舵展开、俯冲回场 → 着陆点火、腿展开、**垂直落回发射台** → 上面级掠过地球弧线 → 标题卡 `AETHER-9 · REUSE THE SKY.`。核心立意：火箭不再是消耗品——"复用天空"。

## 怎么做的（全部代码生成）

- **画面**：`index.html` 内嵌一个 Three.js r180 场景——程序化地球（日夜线/城市光点/大气边缘散射 shader）、渐变天空穹顶（黎明→太空随高度过渡）、21 台发动机喷管阵列 + 马赫环尾焰 shader、点火烟/着陆尘/分离雾粒子系统、栅格舵与着陆腿部署动画。整个飞行是 `renderAt(t)` 的纯函数，通过 `hf-seek` 做确定性渲染。
- **镜头**：手工 keyframe 相机路径（起落机位 → 高空跟拍 → 分离侧拍 → 返回俯冲跟拍 → 轨道横移 → 标题卡），加上程序噪声手持抖动。
- **DOM 层**：GSAP 时间轴驱动双语字幕 pill、HUD 遥测、场景 callout（STAGE SEPARATION / GRID FINS / LANDING BURN / TOUCHDOWN）、标题卡描边揭示。
- **音频**：`bench_tts.py` zh-CN-YunxiNeural 中文旁白 ×10（`assets/voice/`）；`bgm-b.wav` 双段循环，旁白期间 `data-automation` 自动压到 ~16%；tick/rumble(loop)/whoosh/impact 全套 SFX 对位；ffmpeg loudnorm 收 −15.9 LUFS。
- **事实**：只用 `assets/aether9-facts.md`（118m / 9m / 21+6 engines / 120t LEO / T+160s·70km / 4 grid fins / Q2 2027）。

## 复现渲染

```bash
cd aether9-promo
npm run check            # lint + 运行时 + 布局校验（通过：0 error）
npx hyperframes render -o render.mp4   # 输出原始渲染
# final.mp4 = render + loudnorm(-15 LUFS, -1.6dBTP ceiling)
```
