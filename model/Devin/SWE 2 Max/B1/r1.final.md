# B1 · parking-quote 交付说明

## 交付了什么

`parking-quote/` 目录，纯 Python 标准库实现（3.11+ 可跑，开发验证用 3.14），**零外部依赖**：

- `server.py` — 全部实现：HTTP 路由、输入校验、计费逻辑，约 300 行
- `tests/test_api.py` — 52 个黑盒测试，通过 `BASE_URL` 打运行中的实例，不自起服务
- `bench.json` — `start` / `test` / `health` 约定（`setup` 为空，无需安装）
- `README.md` — 启动、接口、配置说明
- `DECISIONS.md` — 规格未写死处的取舍记录

启动：`PORT=8080 python3 server.py`。测试：`BASE_URL=... python3 tests/test_api.py`。

## 实现上值得一提的

- **整数阿秒（1e-18 s）运算**：所有时间戳解析时转成整数阿秒，`minutes` 的"秒差向上取整"和 22:00 / 06:00 / 自然日边界判定都是精确整数运算，小数秒不会在边界上产生浮点误差。
- **硬编码 UTC+8**：规格明确把本地时间定义为"Asia/Shanghai（UTC+8，无夏令时）"，所以直接 +28800 秒，不依赖 tzdata。
- **统一方法分发**：任何 HTTP 方法都进同一个 dispatcher，保证 404 / 405 语义精确（路径优先于方法），405 带 `Allow` 头；`BENCH_MODE` 关闭时 reset 端点按"路径不存在"处理。
- **错误契约全覆盖**：所有错误（含 HTTP 协议层和兜底异常）都返回 `{"error":{"code","message"}}`；兜底分支返回 400 且只在服务端 stderr 打堆栈，任何输入都不会产生 500。
- **校验顺序**：字段级 400 全部先于业务 422。

## 怎么验证的

本地 Windows + Python 3.14 起两个实例（`BENCH_MODE=1` / 关闭各一）实测：

- 52 个测试全过（`unittest`，含规格示例 90 分钟 = 900 分的完整响应比对）；
- 手工抽查了小数秒夜间边界（`21:59:59.5`→600 vs `22:00:00.001`→300）、单日封顶（4800→4000 `capped:true`）、跨天夜间分段（`22:30` 进场拆成 `300+150 | 450`）、`.5` 进位（1050×0.85→893）、遗失票据在宽限期内也收 5000、7 天整允许/多 1 秒 `TOO_LONG`、不同时区写法等价、400 先于 422 等。

## 已知限制

- 小数秒超过 18 位会截断（对分钟计费无影响）；
- 仅按 `Content-Length` 读请求体，不支持 chunked（常规 HTTP 客户端不受影响）；
- 可选字段显式 `null` 按类型错误处理（严格读法，已写入 DECISIONS.md）。
